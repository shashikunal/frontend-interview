# Show a practical example of using IntersectionObserver lazy images pattern.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9326**

## Overview

Observe placeholder imgs, on first intersect swap data-src into src, unobserve immediately — the classic progressive image loader predating loading=lazy, still superior when custom fade-ins or LQIP swaps accompany loads.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.

## Interactive Code Example

```javascript
const io = new IntersectionObserver((entries, obs) => {
  for (const en of entries) {
    if (!en.isIntersecting) continue;
    const img = en.target;
    img.src = img.dataset.src;
    img.classList.add('loaded');
    obs.unobserve(img);
  }
}, { rootMargin: '200px' });
document.querySelectorAll('img[data-src]').forEach(img => io.observe(img));
```
