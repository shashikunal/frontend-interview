# What does getElementById special behavior look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9054**

## Overview

document.getElementById is the fastest lookup (hash-indexed internally) returning the FIRST element with matching id or null. It exists only on document — not elements — and ignores querySelector syntax entirely (no # prefix). Duplicate ids are invalid HTML but browsers return just the first, masking authoring bugs silently.
