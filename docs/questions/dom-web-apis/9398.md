# Show a practical example of using BroadcastChannel messaging.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9398**

## Overview

new BroadcastChannel(name) connects same-origin tabs/frames sharing the channel: postMessage broadcasts structured clones to siblings EXCLUDING sender, onmessage receives. Cleaner than storage-event hacks for tab coordination (logout everywhere, cache invalidation fanout). close() releases the binding.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
