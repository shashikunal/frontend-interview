# Explain getBoundingClientRect precision in depth.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9440**

## Overview

Returns DOMRect with x/y/width/height/top/right/bottom/left in viewport coordinates INCLUDING transforms; width/height round to integers in some engines — prefer right-left for fractional precision. Forces layout flush; batch reads. Scroll compensation: rect.top + scrollY yields page coordinates.
