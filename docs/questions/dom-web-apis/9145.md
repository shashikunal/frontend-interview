# What does createElementNS for SVG look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9145**

## Overview

SVG lives in the XML namespace — plain createElement produces HTMLUnknownElements that render nothing for svg tags. Use createElementNS("http://www.w3.org/2000/svg", "circle") for namespace-correct creation, or clone <template> contents authored in markup. Attributes like xlink:href historically required namespaced setters.
