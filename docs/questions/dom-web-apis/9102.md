# What common mistakes do developers make with the Range interface?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9102**

## Overview

document.createRange() models a contiguous span between boundary points (startContainer/startOffset, endContainer/endOffset). Ranges select text programmatically, wrap contents (surroundContents), extract/clone fragments (extractContents/cloneContents), measure via getBoundingClientRect, and underpin custom selection UIs and rich-text editors.
