# Show a practical example of using ResizeObserver entry mechanics.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9314**

## Overview

ResizeObserver delivers contentRect (content-box size) and borderBox/devicePixelContentBoxSize variants per entry; loops occur when observing elements resized BY the callback — guard with size comparison or move measurement targets. Essential for chart redraws and container-responsive components media queries cannot express.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
