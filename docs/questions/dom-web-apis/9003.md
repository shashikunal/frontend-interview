# Show a practical example of using the DOMTokenList interface.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9003**

## Overview

DOMTokenList is the ordered collection of space-separated tokens returned by classList, relList, and similar attributes. It offers add, remove, toggle (with force argument), replace, item, contains, length, and forEach — all safer than manual className string surgery because they handle whitespace and duplicates automatically. It is live-ish: changes reflect immediately in the underlying attribute.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
