# What is querySelector and querySelectorAll?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9029**

## Overview

querySelector(css) returns the first element matching a full CSS selector list or null; querySelectorAll returns a STATIC NodeList of all matches in document order. They accept any selector complexity (combinators, pseudo-classes except structural-dynamic quirks in some engines) and can be called on document or any element to scope the search subtree. Prefer them over legacy getters for consistency.
