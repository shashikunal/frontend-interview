# How would you describe beforeinput interception power to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9436**

## Overview

Cancelable beforeinput events (inputType + data + TargetRanges) let editors veto/redirect edits BEFORE mutation — markdown shortcuts, mention triggers, paste sanitization — without post-hoc DOM diffing. The foundation of modern controlled-contenteditable architectures.
