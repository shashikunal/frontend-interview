# What common mistakes do developers make with the Storage interface quotas?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9389**

## Overview

localStorage/sessionStorage implement getItem/setItem/removeItem/clear/key/length storing UTF-16 strings (~5MB origin-wide); quota-exceeded throws on setItem — wrap writes defensively. Storage events broadcast cross-tab mutations (same origin, OTHER tabs only) enabling sync patterns without BroadcastChannel.
