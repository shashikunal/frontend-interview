# Show a practical example of using signal.throwIfAborted usage.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9025**

## Overview

throwIfAborted() throws signal.reason if the signal has fired, otherwise returns undefined. Long-running loops call it between chunks enabling cooperative cancellation without wiring event listeners manually — the cleanest way to honor cancellation in your own async algorithms.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
