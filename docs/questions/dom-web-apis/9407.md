# What is document.cookie constraints?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9407**

## Overview

Cookie reads return ONE semicolon-joined string needing manual parsing; writes set single cookies (name=value; Path; Max-Age; Secure; HttpOnly invisible to JS; SameSite). Size ~4KB per cookie. Prefer CookieStore API (async get/set/getAll with nice types) where available; keep cookies for server-needed state only — storage APIs own the rest.
