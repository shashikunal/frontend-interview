# Show a practical example of using the static vs live NodeList distinction.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9037**

## Overview

querySelectorAll yields a static snapshot — later DOM mutations never alter it. getElementsByClassName/getElementsByTagName yield LIVE HTMLCollections that auto-update as the DOM changes, sometimes mid-loop causing skipped items. Iterating live collections while mutating requires copying ([...collection]) or counting downward.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.

## Interactive Code Example

```javascript
const live = document.getElementsByClassName('item');
const statik = document.querySelectorAll('.item');
console.log(live.length, statik.length); // both 2

document.body.insertAdjacentHTML('beforeend', '<div class="item"></div>');
console.log(live.length, statik.length);   // 3 vs 2 — live updated!
```
