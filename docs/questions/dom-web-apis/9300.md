# What common mistakes do developers make with ClipboardEvent read/write flows?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9300**

## Overview

navigator.clipboard.writeText/readText promise-based (secure contexts); paste events deliver clipboardData.getData("text/html") letting editors sanitize rich pastes BEFORE insertion. copy/cut events populate clipboardData.setData for customized copying (append attribution lines, clean formatting).

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
