# Show a practical example of using URL parsing power moves.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9356**

## Overview

new URL(relative, base) validates and decomposes hrefs: protocol/host/port/pathname/hash plus searchParams URLSearchParams with get/set/append/delete/sort and iterator. url.searchParams.set("page", 2); history.replaceState(null,"",url) updates address bars without reloads cleanly — filter-state-in-URL made trivial.

## Interactive Code Example

```javascript
const url = new URL('/search', location.origin);
url.searchParams.set('q', 'react hooks');
url.searchParams.set('page', '2');
history.replaceState(null, '', url);   // address bar updates, no reload
console.log(url.href); // /search?q=react+hooks&page=2 — encoded correctly
```
