# What does insertBefore precise placement look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9118**

## Overview

parentNode.insertBefore(newNode, referenceNode) inserts before the given child; passing null appends. Despite the name there is no insertAfter — emulate via insertBefore(node, ref.nextSibling). Returns the inserted node enabling chained configuration.
