# Show a practical example of using the HTMLDialogElement interface.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9492**

## Overview

<dialog>.showModal() renders top-layer (above ALL stacking contexts) with ::backdrop, focus trapping, Escape-cancel (cancel + close events); show() runs non-modal inline instead. returnValue captures closing argument; close(result) passes it. Native accessible dialogs finally without focus-trap dependency juggling.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
