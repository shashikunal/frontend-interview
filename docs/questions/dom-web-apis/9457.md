# Show a practical example of using scroll dimension family.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9457**

## Overview

scrollWidth/Height total content extents; scrollTop/Left current offsets assignable for programmatic scrolling (clamped). Reading scrollTop forces layout — virtualized scrollers cache aggressively. Overscroll values can go negative with rubber-banding (iOS) — clamp before math.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
