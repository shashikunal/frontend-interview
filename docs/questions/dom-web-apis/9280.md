# Explain touch events versus pointer migration in depth.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9280**

## Overview

TouchEvents (touchstart/move/end with touches lists) preceded PointerEvents; multi-touch scenarios index multiple simultaneous pointers by identifier. New code prefers pointer events + touch-action CSS; maintain touch handlers only for legacy Safari-era support or exotic multi-touch gestures needing per-finger history.
