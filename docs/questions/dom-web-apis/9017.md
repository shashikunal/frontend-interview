# What common mistakes do developers make with AbortController?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9017**

## Overview

AbortController creates an AbortSignal via its signal property; calling abort(reason) flips signal.aborted to true, fires the abort event, and rejects every operation listening to that signal — fetch requests, event listeners, streams, promises you wire manually. abort() accepts an optional reason exposed as signal.reason. One controller can coordinate cancellation across many consumers, making it the standard cancellation primitive of the web platform.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
