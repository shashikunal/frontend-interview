## Overview

contenteditable="true"/plaintext-only turns elements editable exposing caret/selection machinery; inherit value propagates from parents. Browser-generated markup diverges wildly (spans, divs, br debates) — production editors normalize via execCommand successors or libraries (ProseMirror/Lexical/TipTap) built atop these primitives.
