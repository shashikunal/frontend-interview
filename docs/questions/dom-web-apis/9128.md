# Show a practical example of using textContent vs innerText.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9128**

## Overview

textContent returns ALL text including hidden elements and script/style contents, never triggering layout; innerText approximates RENDERED text, respecting CSS visibility and normalizing whitespace at the cost of forced reflow. Write with textContent (fast, safe — auto-escapes); read display text with innerText only when CSS-awareness matters.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
