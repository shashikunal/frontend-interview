# What common mistakes do developers make with nodeType constants?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9066**

## Overview

Every node carries a numeric nodeType: 1 Element, 3 Text, 8 Comment, 9 Document, 11 DocumentFragment, plus rarer CDATA/processing-instruction types. Modern code rarely checks numbers — instanceof Element/Text or ELEMENT_NODE named constants communicate intent better than magic integers.
