# How would you describe FormData construction and inspection to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9196**

## Overview

new FormData(form) harvests named controls automatically (skipping disabled/nameless/file-vs-text appropriately); programmatic instances append arbitrary Blob/File/string entries for fetch bodies. Inspection: entries()/get()/getAll()/has()/has iteration. Fetching with a FormData body sets multipart encoding automatically — never hand-set Content-Type then.
