# Explain CSSStyleDeclaration inline styling in depth.

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9176**

## Overview

element.style exposes ONLY inline styles: reading returns empty strings for stylesheet-applied values (use getComputedStyle for cascaded results). Property names camelCase (backgroundColor); setting requires units for length values ("10px", not 10). style.setProperty("--custom", v) writes design tokens imperatively — great for JS-driven theming.
