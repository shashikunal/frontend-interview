# What is event.target versus currentTarget?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9241**

## Overview

target identifies where the event ORIGINATED (deepest node); currentTarget identifies what the LISTENER is attached to during dispatch. In delegation handlers currentTarget stays constant while target varies — comparing/routing between them is the essence of bubbled-event architecture. composedPath() exposes the full propagation route.
