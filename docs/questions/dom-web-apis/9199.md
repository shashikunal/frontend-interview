# What is requestSubmit versus submit method?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9199**

## Overview

form.requestSubmit(submitter?) runs full validation and fires submit events honoring the clicked button semantics; legacy form.submit() bypasses validation/events entirely (silent no-validate sends). Programmatic saves should almost always requestSubmit — submit() reserved for genuinely raw bypass cases.
