# Show a practical example of using scrollIntoView options block inline.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9463**

## Overview

scrollIntoView({ behavior:"smooth", block:"start|center|nearest|end", inline }) navigates ancestors as needed; nearest avoids gratuitous jumps. Return-promise support exists in Chromium only — await defensively. Respect reduced-motion by choosing auto behavior conditionally.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
