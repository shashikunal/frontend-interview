# How would you describe DocumentFragment batching to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9095**

## Overview

createDocumentFragment builds detached node groups; appending children costs nothing visually until the fragment mounts in ONE operation triggering single reflow. After insertion the fragment empties itself (children transfer). Modern alternative: building strings or cloning templates — fragments remain the canonical batch-insert primitive.
