# What is the composedPath and shadow piercing?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9247**

## Overview

event.composedPath() returns the propagation node array including shadow-internal ancestors; without composed:true, events stop at shadow boundaries hiding hosts. Reading path[0] reveals the TRUE deepest target even when target appears retargeted to the host element from outside observers.
