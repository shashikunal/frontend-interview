# Show a practical example of using DataTransfer file handling.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9292**

## Overview

drop event dataTransfer.files yields FileList of dropped files; items with kind==="file" enable directory traversal via webkitGetAsEntry where supported. Validate extensions/types server-side too — client MIME checks are advisory only. Upload via FormData appending File objects directly.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
