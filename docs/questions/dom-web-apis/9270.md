# How would you describe PointerEvent unification to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9270**

## Overview

PointerEvents subsume mouse/touch/pen behind one interface adding pointerId, pointerType, pressure, tiltX/Y. setPointerCapture(pointerId) routes subsequent events to the capturing element even off-bounds — essential for reliable sliders/draggables. Feature-detect via window.PointerEvent before subscribing.
