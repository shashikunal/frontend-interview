# What is EventSource SSE interface?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9372**

## Overview

EventSource(url) subscribes to text/event-stream receiving message events plus NAMED events (addEventListener("ticket")) parsed from event: fields; readyState mirrors reconnection status, auto-retry built-in with Last-Event-ID resume headers. close() terminates permanently. Server-sent one-way streaming without websocket ceremony.
