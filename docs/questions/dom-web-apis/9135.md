# What does innerHTML security tradeoffs look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9135**

## Overview

innerHTML parses assignment strings executing embedded img onerror handlers and similar vectors — the classic XSS injection point. Never feed it untrusted input without sanitization (DOMPurify). Legitimate uses: rendering trusted/sanitized rich content, bulk updates outperforming per-node creation. Script tags assigned via innerHTML do not execute.
