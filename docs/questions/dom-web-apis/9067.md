# What is childNodes vs children?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9067**

## Overview

childNodes is a LIVE NodeList including text nodes, comments, and whitespace between tags; children is a LIVE HTMLCollection of element-only members. Counting childNodes.length surprises developers because indentation whitespace creates text nodes — children.length usually matches the intuitive element count.
