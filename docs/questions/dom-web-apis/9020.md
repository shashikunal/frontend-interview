# How would you describe the AbortSignal static helpers to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9020**

## Overview

AbortSignal.timeout(ms) builds a signal that aborts itself after the delay — instant fetch timeouts without controllers. AbortSignal.any([signals]) composes multiple signals into one that aborts when any source aborts, ideal for combining user-cancellation with timeouts. Both signals expose aborted, reason, onabort, throwIfAborted().
