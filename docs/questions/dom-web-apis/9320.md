# Show a practical example of using IntersectionObserver thresholds.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9320**

## Overview

Options: root (viewport default), rootMargin (shrinking/growing box, px/%), threshold array (0–1 ratios firing callbacks crossing points). Entries carry intersectionRatio, isIntersecting, boundingClientRect enabling lazy-load (threshold 0.01), infinite scroll sentinels, viewability analytics (0.5 for half-visible).
