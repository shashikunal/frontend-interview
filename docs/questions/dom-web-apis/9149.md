# How would you describe importNode and adoptNode to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9149**

## Overview

importNode(node, deep) COPIES a node from another document (iframe) keeping ownership there; adoptNode MOVES ownership into the current document. Necessary because cross-document nodes misbehave until imported/adopted. Same-document usage is redundant — cloneNode covers copying locally.
