# Show a practical example of using HTMLSelectElement manipulation.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9219**

## Overview

select.value reflects selected option; select.selectedIndex gives position; options is an HTMLOptionsCollection supporting add/remove/item. Building options: new Option(text, value) then add(). Multiple selects surface selectedOptions list. Mutating option disabled/selected properties updates live — cascading country/state pickers exercise these constantly.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
