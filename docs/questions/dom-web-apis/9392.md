# Show a practical example of using storage event cross-tab sync.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9392**

## Overview

window.addEventListener('storage', e => { e.key, e.newValue, e.oldValue, e.url }) fires in OTHER tabs after localStorage mutations — theme/login-state propagation minus polling. Values arrive as strings; JSON parse defensively since corrupted writers happen.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.

## Interactive Code Example

```javascript
window.addEventListener('storage', e => {
  if (e.key !== 'theme') return;
  applyTheme(JSON.parse(e.newValue ?? '"light"'));
});

// writer tab:
localStorage.setItem('theme', JSON.stringify('dark'));
```
