# Show a practical example of using attribute access versus property access.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9160**

## Overview

setAttribute/getAttribute manipulate STRING attribute values in markup; element properties reflect parsed/live state (input.value tracks typing; input.getAttribute("value") stays at initial markup). Booleans confuse most: checked/disabled attributes only seed initial state. Rule: attributes for markup fidelity, properties for runtime behavior.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.

## Interactive Code Example

```javascript

input.value;                      // 'world' — live property
input.getAttribute('value');      // 'hello' — initial markup string
input.checked = true;
input.getAttribute('checked');    // null unless attribute written explicitly
```
