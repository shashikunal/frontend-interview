# Show a practical example of using the dataset interface.

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9154**

## Overview

dataset exposes data-* attributes as camelCased DOMStringMap properties: data-user-id becomes dataset.userId. Values are always strings — parse numbers/JSON explicitly. Assigning null/undefined stringifies literally; use removeAttribute or delete dataset.key to clear. Delegated handlers read targets’ dataset constantly for parameterized actions.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
