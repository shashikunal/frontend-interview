# What common mistakes do developers make with client dimension family?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9454**

## Overview

clientWidth/Height report visible interior (padding included, borders/scrollbars excluded); clientTop/Left give border widths. Scrollbar presence subtracts from clients — detecting overflow compares scrollWidth>clientWidth. Zero-client-size indicates display:none subtrees, a common mount-time probe.
