# What is listener cleanup via AbortSignal?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9235**

## Overview

Pass one controller signal into every listener registration belonging to a component lifetime; controller.abort() removes them all simultaneously — eliminating bookkeeping arrays of remover functions. Supported broadly in evergreen engines for addEventListener across targets, the tidiest teardown pattern today.
