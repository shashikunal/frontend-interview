# Explain Node.contains in depth.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9079**

## Overview

node.contains(other) reports whether other is the node itself or a descendant — the identity-safe membership test for click-outside detection, drag-drop validation, and focus retention logic. Returns false when either argument is detached from the tree relationships being tested.
