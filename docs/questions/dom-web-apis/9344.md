# Show a practical example of using Response interface consumption.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9344**

## Overview

Response exposes ok/status/statusText/headers (guarded immutability), body as ReadableStream, and one-shot consumers json()/text()/arrayBuffer()/blob()/formData(). Body reuse throws — clone() beforehand when logging AND consuming. redirected flag reveals hop counts; url finalizes post-redirect destination.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
