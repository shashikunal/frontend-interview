# Show a practical example of using visualViewport mobile realities.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9486**

## Overview

window.visualViewport exposes ACTUAL visible area (excluding pinch-zoom shrinkage, on-screen keyboards): scale, offsetLeft/Top, height + resize/scroll events. Fixed bottom bars colliding with keyboards solve by translating with keyboard delta derived from height changes — impossible with plain window resize alone.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.

## Interactive Code Example

```javascript
const vv = window.visualViewport;
function avoidKeyboard() {
  const overlap = Math.max(0, window.innerHeight - vv.height - vv.offsetTop);
  footer.style.transform = `translateY(-${overlap}px)`;
}
vv.addEventListener('resize', avoidKeyboard);
```
