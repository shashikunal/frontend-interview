# What common mistakes do developers make with pointer capture practical slider?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9278**

## Overview

Capturing on pointerdown lets thumb tracking continue outside bounds; releasePointerCapture (or implicit release on pointerup) ends routing. Combine with touch-action:none CSS preventing scroll gesture theft during horizontal drags.
