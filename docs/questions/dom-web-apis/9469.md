# Show a practical example of using elementFromPoint hit testing.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9469**

## Overview

document.elementFromPoint(x, y) returns topmost rendered element at viewport coordinates or null (outside/none-rendered); elementsFromPoint stacks the full z-order — drag-drop targeting, custom cursors, and click-through debugging lean on these constantly. Pointer-events:none elements are transparent to hits.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
