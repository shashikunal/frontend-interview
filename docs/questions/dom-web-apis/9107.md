# What does insertAdjacentHTML positions look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9107**

## Overview

element.insertAdjacentHTML(position, html) parses HTML and inserts at four positions: beforebegin, afterbegin, beforeend, afterend — relative to the element. Faster than innerHTML reassignment because existing children survive untouched; still executes scripts? No — script tags inserted this way do NOT run, but event-handler attributes become live, so sanitize untrusted input.
