# Show a practical example of using Drag and Drop API essentials.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9286**

## Overview

Native DnD: draggable=true sources fire dragstart (set effectAllowed, stash data via dataTransfer.setData), drop zones respond to dragover (MUST preventDefault to allow dropping) and drop (getData). DataTransfer.items expose files during drops. Infamous browser inconsistencies keep libraries popular, but zero-dependency file-drop zones work natively well.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.

## Interactive Code Example

```javascript
src.addEventListener('dragstart', e => {
  e.dataTransfer.setData('text/plain', src.id);
  e.dataTransfer.effectAllowed = 'move';
});
zone.addEventListener('dragover', e => e.preventDefault()); // REQUIRED to allow drop
zone.addEventListener('drop', e => {
  e.preventDefault();
  const id = e.dataTransfer.getData('text/plain');
  zone.appendChild(document.getElementById(id));
});
```
