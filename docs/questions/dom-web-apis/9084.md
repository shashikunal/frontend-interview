# Explain TreeWalker deep traversal in depth.

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9084**

## Overview

document.createTreeWalker(root, filter) yields a cursor-based walker with currentNode navigation: nextNode(), previousNode(), firstChild() etc., honoring NodeFilter callbacks (FILTER_ACCEPT/SKIP/REJECT) evaluated per candidate. SKIP skips the node but descends children; REJECT prunes whole subtrees (elements only). Ideal for filtered deep scans without recursion.
