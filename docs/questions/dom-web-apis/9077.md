# What common mistakes do developers make with firstChild vs firstElementChild?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9077**

## Overview

firstChild/lastChild/nextSibling/previousSibling navigate raw node boundaries where whitespace text nodes frequently intervene; the Element-suffixed versions (firstElementChild etc.) skip non-element nodes giving predictable traversal regardless of formatting. Default to Element variants unless manipulating comments/text deliberately.
