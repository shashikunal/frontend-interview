# What does append and prepend modern insertion look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9113**

## Overview

Parent.append()/prepend()/replaceChildren() accept multiple nodes AND strings (auto-text-converted), unlike appendChild’s single-node contract. append appends after last child; prepend inserts before first; replaceChildren clears-and-fills atomically — the cleanest refresh pattern for dynamic containers.
