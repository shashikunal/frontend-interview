# Show a practical example of using EventTarget listener registration.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9231**

## Overview

addEventListener(type, handler, options) — options object supports capture, once (auto-remove after fire), passive (perf hint promising no preventDefault), and signal (AbortSignal auto-removal — modern cleanup champion). Duplicate identical registrations are ignored; arrow wrappers break removal identity so keep references.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
