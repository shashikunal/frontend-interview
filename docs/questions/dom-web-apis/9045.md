# What common mistakes do developers make with NodeList methods and iteration?

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9045**

## Overview

Modern NodeList implements forEach, item, keys, values, entries plus Symbol.iterator so spread/for-of work. It lacks map/filter/reduce — convert via Array.from(list) or [...list] when array methods are needed. Static NodeLists from querySelectorAll are snapshots; remember conversion copies references, elements themselves stay shared.
