# Show a practical example of using the ValidityState interface.

> **Category:** DOM & Web APIs | **Difficulty:** Hard | **Question #9207**

## Overview

input.validity exposes flags: valueMissing, typeMismatch, patternMismatch, tooLong/short, rangeUnder/overflow, stepMismatch, badInput, customError, culminating in valid booleans. Drive custom error UI from these flags instead of regex duplication — the browser already computed constraint violations per its validation attributes.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
