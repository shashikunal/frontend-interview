# Show a practical example of using textarea selection APIs.

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9225**

## Overview

selectionStart/selectionEnd index the caret/selected span within textarea.value; setSelectionRange(start, end, direction?) positions programmatically (must run post-focus); setRangeText replaces spans honoring selection modes. Powering autocomplete carets, mention highlighting, and undoable insertions in editors built on plain textareas.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
