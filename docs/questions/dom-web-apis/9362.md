# Show a practical example of using URLSearchParams encoding discipline.

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9362**

## Overview

SearchParams percent-encodes correctly per application/x-www-form-urlencoded (spaces as +); URL handles component encoding differences. Manual concatenation breaks on ampersands/unicode — always route dynamic values through the API. sort() canonicalizes query order enabling cache-key normalization.

Study the example above: it demonstrates the typical usage pattern and the pitfalls to avoid.
