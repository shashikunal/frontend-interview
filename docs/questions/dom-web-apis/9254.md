# How would you describe MouseEvent coordinate families to a teammate?

> **Category:** DOM & Web APIs | **Difficulty:** Easy | **Question #9254**

## Overview

clientX/Y relative to viewport; pageX/Y adds scroll offset; screenX/Y relative to physical monitor; offsetX/Y relative to target padding box. Dragging math typically wants client coords + rect deltas; canvas painting wants offsetX. Mixing families causes cursor-jump bugs — name the frame explicitly in code reviews.
