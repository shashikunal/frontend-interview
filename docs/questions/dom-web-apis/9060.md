# What does closest and matches navigation look like in practice, and when does it matter?

> **Category:** DOM & Web APIs | **Difficulty:** Medium | **Question #9060**

## Overview

matches(selector) tests whether an element satisfies a selector; closest(selector) walks UP the ancestor chain (including the element itself) returning the first match — essential for event delegation routing clicks to semantic containers. Both throw SyntaxError on invalid selectors.
