# What does minmax and fr distribution look like in practice, and when does it matter?

> **Category:** CSS | **Difficulty:** Medium | **Question #7104**

## Overview

minmax(min, max) bounds track sizing; fr distributes leftover space after fixed/min-content demands — not pure fractions of total. minmax(0,1fr) rescues overflowing children (min-content floor defeated) in equal-column layouts containing wide tables.
