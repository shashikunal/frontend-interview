# What is text truncation single line?

> **Category:** CSS | **Difficulty:** Easy | **Question #7211**

## Overview

white-space:nowrap + overflow:hidden + text-overflow:ellipsis clips gracefully with ellipsis. Works on block containers with constrained width. Table cells need max-width set. Provide title/full-text affordances since truncation hides information.
