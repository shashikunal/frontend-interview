# What is print styles essentials?

> **Category:** CSS | **Difficulty:** Hard | **Question #7256**

## Overview

@media print hides nav/chrome, expands links with href after text, forces black-on-white, avoids page-break-inside on cards/tables, sets margins via @page. URL expansion uses ::after content attr(href). Test via browser print preview before shipping invoices/articles.
