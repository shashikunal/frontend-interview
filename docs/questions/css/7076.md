# What is align-self and order?

> **Category:** CSS | **Difficulty:** Easy | **Question #7076**

## Overview

align-self overrides container alignment per item enabling mixed baselines; order reorders visually without DOM changes — powerful yet screen-reader/DOM-order divergence hazard. Prefer source-order solutions; use order only for genuinely presentational rearrangement.
