# What is overscroll-behavior control?

> **Category:** CSS | **Difficulty:** Easy | **Question #7516**

## Overview

overscroll-behavior: contain stops scroll chaining (inner modal scroll no longer scrolls page beneath); none disables bounce/rubber-band too. Fixes the infamous pull-to-refresh-inside-widget accidents and scroll-trap complaints in embedded panes.
