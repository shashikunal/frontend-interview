# Explain nth-child formulas mastery in depth.

> **Category:** CSS | **Difficulty:** Hard | **Question #7267**

## Overview

:nth-child(an+b) selects patterns: odd/even zebra rows, 3n every third, n+5 from fifth onward, -n+3 first three. :nth-last-child counts backward enabling last-N styling. Combined with :not() builds precise slices without classes.
