# Explain initial vs unset vs revert in depth.

> **Category:** CSS | **Difficulty:** Medium | **Question #7017**

## Overview

initial forces the spec default even where inherited normally; unset means inherit if naturally inherited else initial; revert rolls back to user-agent/browser style bypassing author rules entirely. These keywords give surgical reset semantics beyond blanket resets.
