# What common mistakes do developers make with flex-grow shrink basis mechanics?

> **Category:** CSS | **Difficulty:** Easy | **Question #7070**

## Overview

flex-basis sets starting main-size (auto = content); free space distributes by grow ratios, negative space shrinks by shrink*ratio weighted by basis. Default flex:0 1 auto explains squishy buttons; flex:1 shorthand means 1 1 0% equalizing columns regardless of content.
