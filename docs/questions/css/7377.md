# Explain icon fonts vs svg icons in depth.

> **Category:** CSS | **Difficulty:** Medium | **Question #7377**

## Overview

Icon fonts (ligature/charcode mapping) suffer FOUT, accessibility oddities, and single-color limits; inline SVGs style via currentColor, scale crisply, expose proper roles. Sprite sheets (<symbol>/<use>) dedupe markup. SVG won decisively for modern iconography pipelines.
