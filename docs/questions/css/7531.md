# What is user-select and cursor affordances?

> **Category:** CSS | **Difficulty:** Medium | **Question #7531**

## Overview

user-select:none protects interactive controls from accidental text selection (buttons, drag handles) while copy-critical content stays selectable; cursor:pointer signals clickability (non-native clickable divs NEED it), grab/grabbing communicates draggability. Affordance honesty beats aesthetic purity.
