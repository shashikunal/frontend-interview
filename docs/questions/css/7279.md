# What does :is :where specificity games look like in practice, and when does it matter?

> **Category:** CSS | **Difficulty:** Medium | **Question #7279**

## Overview

:is() takes complex selectors listing alternatives with highest-argument specificity; :where() zeroes specificity entirely — perfect for reset defaults overridden effortlessly later. Composing :where(:is(a,b)) balances ergonomics and neutrality deliberately in design-system foundations.
