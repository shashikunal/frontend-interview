# Deep dive: What is object-fit cover vs contain?

> **Category:** CSS | **Difficulty:** Hard | **Question #7683**

## Overview

For replaced elements (img/video): cover fills box cropping overflow (hero images); contain letterboxes preserving whole asset (product shots). object-position biases crop focal point. Without object-fit images stretch/distort whenever intrinsic ratio mismatches container.
