# Quick check: what is the CSS cascade?

> **Category:** CSS | **Difficulty:** Easy | **Question #7541**

## Overview

The cascade resolves competing declarations by origin/importance, layer, specificity, source order, and inheritance. Later same-specificity rules win; !important inverts author order within its origin. Cascade layers (@layer) now insert an explicit precedence tier between importance and specificity for architecture-level control.
