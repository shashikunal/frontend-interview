# How would you describe outline vs border differences to a teammate?

> **Category:** CSS | **Difficulty:** Easy | **Question #7208**

## Overview

Outlines draw outside layout flow (no space taken), don’t follow border-radius historically (now they do), and serve focus indicators accessibly. outline-offset spaces indicator from edge. Never remove focus outlines without :focus-visible styled replacements — keyboard users depend on them.
