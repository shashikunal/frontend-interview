# Quick check: what is svg inline vs img tradeoffs?

> **Category:** CSS | **Difficulty:** Hard | **Question #7621**

## Overview

Inline SVG styles internally (currentColor, part styling) and animates via CSS but bloats HTML/caching; img/svg references cache cleanly but resist styling. Sprites balance: symbol definitions once, use references everywhere, currentColor propagation intact.
