# What is touch-action manipulation?

> **Category:** CSS | **Difficulty:** Hard | **Question #7521**

## Overview

touch-action controls gesture handling: none disables browser panning/zoom for canvas apps; manipulation keeps panning/pinch but kills double-tap-zoom delay; pan-y restricts horizontal carousels to vertical page scroll coexistence. Misuse breaks accessibility zoom — scope narrowly.
