# Senior-level follow-up: What common mistakes do developers make with srcset and sizes attributes?

> **Category:** CSS | **Difficulty:** Easy | **Question #7941**

## Overview

srcset lists candidate resolutions (image.jpg 1x/2x or w-descriptors); sizes tells browser rendered slot width letting it choose optimal download. Prevents 3000px desktop images on phones — biggest mobile perf win with pure markup. Always pair with width/height attrs reserving space.
