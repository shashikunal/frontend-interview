# Explain prefers-reduced-motion respect in depth.

> **Category:** CSS | **Difficulty:** Hard | **Question #7237**

## Overview

@media (prefers-reduced-motion: reduce) disables/shortens animations/transitions/parallax preventing vestibular distress. Wrap motion behind the query globally via shared mixins/utilities. Motion should communicate, never decorate at users’ expense — this query encodes that ethic.

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
