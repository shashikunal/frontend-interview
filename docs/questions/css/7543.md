# Quick check: how would you describe inheritance in CSS to a teammate?

> **Category:** CSS | **Difficulty:** Easy | **Question #7543**

## Overview

Inherited properties (color, font, line-height, text-align) flow parent-to-child unless overridden; box-model and layout properties do not inherit. inherit/initial/unset/revert keywords control the behavior explicitly per property. Design systems exploit inheritance by setting typography once on body.
