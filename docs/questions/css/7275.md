# What common mistakes do developers make with nth-of-type vs nth-child?

> **Category:** CSS | **Difficulty:** Hard | **Question #7275**

## Overview

:nth-child counts ALL sibling elements regardless of type; :nth-of-type counts only matching tag types. Mixed markup (spans among divs) diverges results — classic bug source. Prefer structural consistency or explicit classes when mixing element types inside selection containers.
