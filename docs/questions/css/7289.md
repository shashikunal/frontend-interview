# What does focus-visible vs focus look like in practice, and when does it matter?

> **Category:** CSS | **Difficulty:** Easy | **Question #7289**

## Overview

:focus-visible fires for keyboard/heuristic focus only, sparing mouse-click outlines while keeping keyboard visibility — replacing hacky focus ring suppression scripts. :focus matches all focus for programmatic restyling. Style both thoughtfully: visible rings for keyboard, custom states for pointer.
