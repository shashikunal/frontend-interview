# Deep dive: What is system font stacks?

> **Category:** CSS | **Difficulty:** Medium | **Question #7723**

## Overview

System stacks (-apple-system, Segoe UI, Roboto...) ship zero network cost with native look; modern font-family: system-ui encapsulates preference. Tradeoff: cross-platform inconsistency. Many design systems pair system-ui for UI chrome with branded webfonts for headings only.
