# Deep dive: What is custom properties var fallbacks?

> **Category:** CSS | **Difficulty:** Medium | **Question #7693**

## Overview

--tokens store reusable values consumed via var(--token, fallback); fallback handles undefined tokens gracefully. Properties inherit and cascade like normal values, are runtime-editable via JS enabling theme switching without recompilation, and cannot hold media-query logic themselves.
