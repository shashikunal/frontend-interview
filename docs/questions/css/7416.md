# What is masking images css?

> **Category:** CSS | **Difficulty:** Easy | **Question #7416**

## Overview

mask-image uses luminance/alpha of another image/gradient to hide portions — fade-out edges (mask linear-gradient), icon tinting via alpha masks. Prefix history (-webkit-mask) lingers; mask-composite combines layers. More flexible than clip-path for soft-edged effects.
