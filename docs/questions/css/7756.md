# Deep dive: What does pointer-events none passthrough look like in practice, and when does it matter?

> **Category:** CSS | **Difficulty:** Hard | **Question #7756**

## Overview

pointer-events:none makes elements click-transparent — overlay decorations stop blocking underlying buttons; re-enable auto on children selectively. Disabled-looking-but-hover-animated elements, drag ghosts, and map-under-overlay patterns rely on this escape hatch.
