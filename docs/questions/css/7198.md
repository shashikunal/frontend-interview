# How would you describe filters and backdrop-filter to a teammate?

> **Category:** CSS | **Difficulty:** Medium | **Question #7198**

## Overview

filter applies blur/brightness/grayscale to element contents; backdrop-filter processes what lies BEHIND (glassmorphism frosted panels). Both create stacking/containing contexts affecting fixed positioning. Performance: large blurred areas cost paint — test low-end devices.

- Array iteration methods

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
