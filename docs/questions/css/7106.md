# What is grid item placement lines?

> **Category:** CSS | **Difficulty:** Medium | **Question #7106**

## Overview

Items position via grid-line numbers (grid-column: 1 / 3), spans (span 2), or named lines [-main-start]. Overlapping placements create layered cells without z-index ceremony. Line-based control powers editorial/magazine layouts impossible in flexbox.
