# How would you describe placeholder and selection styling to a teammate?

> **Category:** CSS | **Difficulty:** Easy | **Question #7303**

## Overview

::placeholder styles input hints (maintain contrast — placeholders are not labels); ::selection colors highlighted text brand-consistently. Both historically vendor-prefixed; modern browsers accept unprefixed. Placeholder color contrast failures are common axe findings worth proactive styling.
