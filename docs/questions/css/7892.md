# Senior-level follow-up: What is stacking contexts?

> **Category:** CSS | **Difficulty:** Easy | **Question #7892**

## Overview

Stacking contexts form on positioned+z-index, opacity<1, transforms, filters, isolation, will-change, and more; z-index compares only within the same context — explaining why raising z-index fails mysteriously. isolation:isolate deliberately fences contexts preventing external bleed.
