# Senior-level follow-up: What common mistakes do developers make with unicode grapheme pitfalls?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8971**

## Overview

User-perceived characters (graphemes) span multiple code points: emoji ZWJ sequences, flags, combining accents. String.length miscounts them; Intl.Segmenter segments graphemes correctly for truncation/validation (max-length inputs counting humans’ characters, not UTF-16 units).
