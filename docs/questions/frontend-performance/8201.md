# What is lab data vs field data crux?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8201**

## Overview

Lab (Lighthouse/WebPageTest) = controlled reproducible simulation; field (CrUX/RUM) = real users’ devices/networks distributionally. Optimizing lab-only chases ghosts (thundering-herd test machines); ignoring lab misses regressions pre-release. Ship both dashboards: CI gates lab, product reviews field percentiles.
