# Rapid fire: how would you describe reflow vs repaint costs to a teammate?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8996**

## Overview

Reflow (layout) recomputes geometry cascading subtree-wide — expensive; repaint redraws pixels without geometry — cheaper; compositor-only updates cheapest. Property change categories determine cost tiers: geometry properties worst, color medium, transform/opacity best.
