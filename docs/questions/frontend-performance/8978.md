# Rapid fire: what common mistakes do developers make with fetchpriority attribute?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8978**

## Overview

fetchpriority=high|low|auto adjusts resource priority beyond browser heuristics: hero LCP image high, below-fold carousel images low. Pairs with loading=eager for LCP heroes contradicting blanket lazy-loading advice. Chrome DevTools network waterfall exposes computed priorities for tuning.
