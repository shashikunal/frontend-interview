# What common mistakes do developers make with retry idempotency discipline?

> **Category:** Frontend Performance | **Difficulty:** Easy | **Question #8330**

## Overview

Retry only idempotent verbs (GET/PUT/DELETE) blindly; POST retries duplicate creations unless idempotency-keys sent (Stripe pattern) letting servers dedupe. Exponential backoff with jitter prevents synchronized retry storms. Respect Retry-After headers honoring rate limits politely.
