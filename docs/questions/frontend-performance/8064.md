# What does stale-while-revalidate pattern look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8064**

## Overview

Cache-Control: max-age=1, stale-while-revalidate=86400 serves cached content instantly while fetching fresh asynchronously — users get zero-latency reads with eventual consistency. Ideal for semi-dynamic content: dashboards, listings. Not for auth-sensitive or rapidly-mutating data.
