# What common mistakes do developers make with long tasks and TBT?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8160**

## Overview

Tasks exceeding 50ms block input responsiveness accumulating Total Blocking Time; find via DevTools Performance/Lighthouse. Fixes: code-splitting shrinking eval, breaking mega-tasks into yielded slices (scheduler.yield/setTimeout), moving computation to workers. TBT correlates strongly with INP frustration.
