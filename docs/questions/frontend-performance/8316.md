# What is api pagination strategies?

> **Category:** Frontend Performance | **Difficulty:** Easy | **Question #8316**

## Overview

Offset pagination jumps randomly but drifts under concurrent inserts; cursor pagination (opaque tokens) stays stable scaling infinitely; infinite-scroll UX pairs cursors naturally while page-number UX aids direct linking/deep jumps. Always cap page sizes server-side defending against dump-requests.
