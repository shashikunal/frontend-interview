# What does streaming ssr flush timing look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8304**

## Overview

Streaming sends HTML shell immediately flushing Suspense boundaries as data resolves — browsers start painting before full document arrives. Flush order matters: shell-first beats data-blocking; out-of-order streaming inserts placeholders swapped later. Perceived speed improves even when total time identical.
