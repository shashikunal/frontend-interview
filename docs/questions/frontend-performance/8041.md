# What is HTTP/2 multiplexing benefits?

> **Category:** Frontend Performance | **Difficulty:** Easy | **Question #8041**

## Overview

H2 streams multiple requests over one connection killing head-of-line blocking at HTTP level, making sprite-sheets/domain-sharding obsolete; server push failed practically. H3/QUIC extends gains fixing TCP-level HOL and improving lossy mobile networks via UDP transport.
