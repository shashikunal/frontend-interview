# What is estimation uncertainty communication?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8461**

## Overview

Estimate ranges with confidence framing, decompose until uncertainty shrinks, re-forecast at checkpoints openly. Reference-class forecasting (similar past work) beats optimism anchoring. Stakeholders need decision-grade confidence statements, not false precision theater.
