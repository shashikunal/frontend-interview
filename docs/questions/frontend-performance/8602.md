# Quick check: explain data waterfalls elimination in depth.

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8602**

## Overview

Sequential awaits (auth→user→posts) multiply latencies; parallelize independent fetches (Promise.all), colocate data requirements with components enabling topological scheduling (RSC/loaders), cache/dedupe repeated keys, prefetch predictable next queries during idle. Waterfalls hide inside component trees silently.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
