# Deep dive: What does compositor thread advantages look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8671**

## Overview

Compositor handles transform/opacity layers off main thread — animations stay smooth even during JS stalls. Layer promotion costs memory/GPU upload; excessive layers (will-change spam) backfire. Promote strategically: scrolling panes, animating elements, nothing else without measurement.
