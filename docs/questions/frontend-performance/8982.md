## Overview

QUIC over UDP integrates TLS 1.3 handshakes slashing connection setup RTTs, survives IP changes (wifi→cellular handoffs), and avoids TCP head-of-line blocking across streams. Requires UDP-permitting networks/firewalls; fallback to H2 automatic. Real-world mobile latency wins are measurable.
