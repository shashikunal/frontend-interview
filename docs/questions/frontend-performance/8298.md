# How would you describe hydration cost islands architecture to a teammate?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8298**

## Overview

Full-page hydration ships/executes entire component tree JS despite static majority; islands hydrate interactive widgets only (Astro pattern) shipping dramatically less JS. Selective/streaming hydration prioritizes visible/interacting regions progressively. Architecture-level answer to JS-bloat complaints.
