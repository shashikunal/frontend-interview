# What does permissions policy feature gating look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Easy | **Question #8419**

## Overview

Permissions-Policy header disables powerful features (camera/geolocation/fullscreen) for your page and embedded iframes — defense against malicious ad iframes abusing permissions under your origin’s reputation. Allowlist model: default deny, grant explicitly to trusted embeds only.
