# What common mistakes do developers make with render tree formation?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8010**

## Overview

Render tree combines DOM nodes with matched styles excluding display:none subtrees and including pseudo-elements; visibility:hidden stays rendered. Layout computes geometry per node; changes forcing reflow cascade through affected trees. Understanding what enters the tree explains why some hidden elements still cost layout.
