# Explain passive event listeners impact in depth.

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8147**

## Overview

{passive:true} promises no preventDefault letting browsers scroll immediately without handler-completion waits — wheel/touch defaults now passive in Chrome. Non-passive listeners on document scroll remain a Lighthouse warning worth auditing. Always passive unless cancellation genuinely needed.
