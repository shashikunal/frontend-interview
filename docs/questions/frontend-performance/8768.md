# Interview scenario — what does etag vs last-modified revalidation look like in practice, and when does it matter?

## Overview

Validators let caches ask "still fresh?" cheaply: ETag fingerprints content (strong/weak variants), Last-Modified timestamps coarse. 304 responses skip bodies saving bandwidth though not round trips. Content-hashed assets skip validation entirely via immutable max-age.
