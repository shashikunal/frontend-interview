# Rapid fire: what is modulepreload?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8979**

## Overview

modulepreload fetches AND parses/compiles module graphs ahead resolving dependency chains, unlike plain preload’s fetch-only. Critical route chunks listed in head eliminate cold-start module waterfall cascades that dynamic imports create serially.
