# Deep dive: What does csrf protection sameSite look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8726**

## Overview

CSRF tricks browsers sending cookies cross-site; SameSite=Lax/Strict cookie flags neutralize most vectors modernly; legacy fallbacks use synchronizer tokens double-submitting. CORS blocks reading responses but NOT state-changing sends — hence CSRF remains its own concern distinct from CORS.
