# Deep dive: What is brotli vs gzip compression?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8663**

## Overview

Brotli compresses text 15-25% smaller than gzip at comparable speeds (static precompression excels further); all modern browsers send Accept-Encoding: br. Serve brotli-static where possible, dynamic brotli-1..5 levels balancing CPU; gzip remains the universal floor.
