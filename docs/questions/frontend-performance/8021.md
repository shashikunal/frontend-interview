# What is preload prefetch preconnect?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8021**

## Overview

preload fetches critical current-navigation resources early (fonts, hero image) with as-type priority; prefetch hints likely NEXT navigations at idle; preconnect warms DNS+TCP+TLS to third-party origins cutting handshake latency. dns-prefetch is the cheap legacy subset of preconnect.
