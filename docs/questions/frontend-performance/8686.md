# Deep dive: What does detached node leaks look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8686**

## Overview

JS references (arrays, closures, stores) holding removed DOM nodes prevent GC — heap snapshots label them Detached. Common culprits: caches keyed by elements, infinite undo stacks of removed subtrees, framework cleanup missed in manual integrations. Null-out references on teardown.
