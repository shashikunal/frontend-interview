# Senior-level follow-up: What is defer vs async scripts?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8867**

## Overview

async downloads parallel executing immediately on arrival (order unpredictable); defer downloads parallel executing in order before DOMContentLoaded. Both unblock parsing versus synchronous scripts halting it. App bundles want defer (or module default); independent analytics tolerate async.

## Key Concepts

- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
