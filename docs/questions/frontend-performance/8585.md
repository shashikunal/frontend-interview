# Quick check: what common mistakes do developers make with CLS cumulative layout shift fixes?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8585**

## Overview

Shifts stem from dimension-less media, late-loading fonts/ads/embeds, dynamically injected banners above content. Fix: explicit width/height/aspect-ratio everywhere, size-adjust font fallbacks, reserved ad slots, transform-based insertions (transform doesn’t shift layout), skeletons mirroring final layouts.
