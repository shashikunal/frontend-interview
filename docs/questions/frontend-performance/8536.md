# What is encoding utf8 emoji surrogates?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8536**

## Overview

Astral emoji encode surrogate PAIRS in UTF-16: naive half-pair slicing corrupts output producing replacement diamonds. Code-point aware ops ([...str], u-flag regex, Intl.Segmenter) preserve integrity. Validation regexes without u flag match half-pairs dangerously accepting broken strings.
