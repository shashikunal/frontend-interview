# What does layout thrashing diagnosis look like in practice, and when does it matter?

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8099**

## Overview

Alternating reads (offsetHeight) and writes (style.width) in loops forces sync layout each iteration — thrashing. Fix batch reads then writes, use FastDOM-style scheduling, or transform-only animations avoiding layout entirely. DevTools Performance panel purple Layout blocks expose offenders.
