# What is design tokens pipelines?

> **Category:** Frontend Performance | **Difficulty:** Hard | **Question #8421**

## Overview

Tokens (color/spacing/typography primitives) authored once (Figma/design repo) transform via Style Dictionary into CSS vars/iOS/Android outputs — single source syncing platforms. Semantic layer (surface-primary) sits atop primitives enabling theme swaps without component edits.
