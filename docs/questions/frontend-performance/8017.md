# Explain module scripts behavior in depth.

> **Category:** Frontend Performance | **Difficulty:** Medium | **Question #8017**

## Overview

<script type="module"> defers automatically, runs strict, gets own scope, supports imports, executes after parsing but before DOMContentLoaded fires. Legacy UMD tags converted to modules gain deferred semantics free. nomodule serves fallbacks to ancient browsers when dual-shipping.
