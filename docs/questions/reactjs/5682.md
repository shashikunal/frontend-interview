# Deep dive: What is useState hook?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5682**

## Overview

useState returns [value, setter] pair; calling setter schedules re-render with new value. Initial value evaluates once (pass function for expensive init). Setters with identical Object.is value bail out re-renders. Multiple states compose naturally versus one giant object needing spread merges.
