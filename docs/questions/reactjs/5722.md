# Deep dive: What is state colocation principle?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5722**

## Overview

Keep state as close to its consumers as possible — local state stays local, lifting only when sharing demands. Colocation shrinks re-render scope, simplifies reasoning, eases testing. Global stores hoarding everything recreates the spaghetti state management was meant to fix.
