# Senior-level follow-up: Explain React.memo shallow compare in depth.

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5930**

## Overview

memo wraps components skipping re-render when props shallow-equal previous. Objects/arrays/functions created fresh per render defeat it unless parent memoizes them too. Custom comparators exist but hide bugs; prefer memoizing upstream values or restructuring props to primitives over deep-compare escapes.
