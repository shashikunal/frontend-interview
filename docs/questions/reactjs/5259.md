# What does Redux Toolkit advantages look like in practice, and when does it matter?

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5259**

## Overview

RTK eliminates action-type strings via createSlice auto-generating actions/reducers, bundles immer for ergonomic immutable updates, configures devtools/thunk defaults, and offers RTK Query for data fetching with caching. New Redux projects start with RTK; hand-rolled legacy patterns persist mainly in old codebases.
