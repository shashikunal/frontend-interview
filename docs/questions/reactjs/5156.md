# What is useMemo purpose and misuse?

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5156**

## Overview

useMemo caches computation between renders keyed by dependencies, skipping recalculation and preserving referential equality for downstream memo/effect deps. Misuse includes wrapping trivial math adding overhead, and relying on it semantically — cache may be discarded anytime, so correctness must survive recomputation.
