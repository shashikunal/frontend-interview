# What is useOptimistic?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5366**

## Overview

useOptimistic wraps state showing speculative values during pending async actions, reverting automatically on completion/error. Form-heavy flows feel native-app instant. Combine with useActionState for full optimistic form pipelines including validation feedback loops.
