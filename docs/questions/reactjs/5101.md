# What is effect cleanup patterns?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5101**

## Overview

Cleanup unsubscribes listeners, clears timers, aborts fetches, closes sockets — running before next effect execution and on unmount. Forgetting cleanup leaks memory and causes ghost handlers firing on dead components. StrictMode intentionally mounts-unmounts-mounts exposing missing cleanups early in development.
