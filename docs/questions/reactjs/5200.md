# What common mistakes do developers make with StrictMode double rendering?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5200**

## Overview

Development StrictMode invokes render functions twice and mounts/unmounts/remounts effects once, surfacing impure renders and missing cleanups. Production skips this entirely. Treat it as free audit tooling: code breaking under StrictMode harbors latent production bugs involving side effects in render paths.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
