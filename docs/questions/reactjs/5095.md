# What common mistakes do developers make with uncontrolled inputs?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5095**

## Overview

Uncontrolled inputs keep DOM as source of truth read via refs on demand (formData/FormData API shines here). They skip per-keystroke re-renders and integrate legacy plugins easily. File inputs are inherently uncontrolled since value is write-only for security.
