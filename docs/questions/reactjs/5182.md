# Explain custom hooks extraction in depth.

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5182**

## Overview

Custom hooks are functions calling other hooks sharing stateful logic across components: useToggle, useDebounce, useFetch. Name must start with use enabling lint rules. Each caller gets independent state instance — they share code, not state (that’s context/store territory).
