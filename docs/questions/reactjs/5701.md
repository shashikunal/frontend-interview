# Deep dive: What common mistakes do developers make with ref vs state choice?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5701**

## Overview

Choose state when UI should re-render on change; choose ref when value matters only to event handlers/effects (interval ids, previous props, mounted flags). Rule: rendering output depends on it → state; imperative logic depends on it → ref.
