# Deep dive: Explain lifting state up in depth.

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5688**

## Overview

When sibling components need shared data, move state to nearest common ancestor passing values/callbacks down. This keeps single source of truth though creates prop-drilling at depth. Combine with context or composition (passing components) to relieve drilling pressure selectively.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
