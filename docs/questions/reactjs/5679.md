# Deep dive: How would you describe components as functions to a teammate?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5679**

## Overview

Function components receive props and return description trees; React calls them repeatedly treating each call as pure-ish render. Side effects belong in effects/handlers not render bodies. Function identity changes per render, which is why memoization hooks exist.
