# Senior-level follow-up: How would you describe keys in lists to a teammate?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5901**

## Overview

Keys give elements stable identities across renders letting React reorder instead of recreate. Use unique data ids — never array indices when lists reorder/filter, which causes state bleed between items and input focus bugs. Keys need uniqueness among siblings only.
