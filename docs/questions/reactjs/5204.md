# What does error boundaries look like in practice, and when does it matter?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5204**

## Overview

Error boundaries catch render/lifecycle errors in child subtrees displaying fallbacks — implemented via componentDidCatch/getDerivedStateFromError classes or react-error-boundary library. They miss event handlers, async callbacks, and server errors; those need try/catch + state. Boundary placement strategy: route-level coarse plus widget-level surgical recovery.
