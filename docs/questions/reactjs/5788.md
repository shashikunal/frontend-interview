# Interview scenario — what is reconciliation and diffing?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5788**

## Overview

Reconciliation compares element trees assuming: different element types tear down and rebuild subtrees; same types update props in place; keyed lists match children by key enabling moves. These heuristics turn O(n^3) tree diffing into practical O(n) updates.
