# Deep dive: What is infinite useEffect loops?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5697**

## Overview

Loops occur when effects setState values listed in their own dependencies, or dependencies are inline objects/functions recreated each render. Break cycles: derive during render instead, stabilize references with useMemo/useCallback, or restructure so effects consume refs. DevTools profiler visualizes the ping-pong commits.
