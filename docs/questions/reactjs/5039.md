# What does props look like in practice, and when does it matter?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5039**

## Overview

Props are read-only inputs flowing down from parents. Mutating them breaks one-way data flow assumptions; instead lift changes via callbacks. children prop carries nested elements enabling composition wrappers. Default values via destructuring defaults keep components resilient.
