# Explain useRef in depth.

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5137**

## Overview

useRef returns stable { current } box surviving renders without triggering re-render on mutation. Primary uses: DOM node access, mutable instance values (timer ids, previous values), latest-value holders for stale-closure immunity. Writing ref.current during render is forbidden — do it in effects/handlers.
