# Interview scenario — what is derived state anti-pattern?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5798**

## Overview

Copying props into state via useEffect duplicates truth causing sync bugs; compute derived values during render instead (const total = price * qty). If derivation is expensive, useMemo caches. Resetting state on prop change legitimately needs key-remount pattern or tracked-prev-state comparison.
