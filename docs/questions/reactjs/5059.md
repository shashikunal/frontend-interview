# What does state batching look like in practice, and when does it matter?

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5059**

## Overview

React 18 batches all updates automatically — multiple setters inside promises/timeouts/native handlers commit once, unlike legacy auto-batching limited to React event handlers. flushSync opts out when reading DOM between updates is unavoidable (rare measurement cases).

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
