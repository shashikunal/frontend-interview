# Deep dive: Explain context vs store decision matrix in depth.

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5733**

## Overview

Context fits low-frequency global config (theme, locale, auth user). Stores fit high-frequency updates, cross-tree selectors, middleware needs. Litmus: does every consumer want every change? Context yes-consumers all rerender; stores filter via selectors. Hybrid architectures combine both deliberately.
