# What is useDeferredValue?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5361**

## Overview

useDeferredValue(input) returns lagging copy scheduling dependent renders at lower priority — alternative to transition-wrapping when modifying the producer is inconvenient (child components, third-party inputs). Pair with memoized heavy children so deferred renders actually skip redundant work.
