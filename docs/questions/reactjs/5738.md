# Deep dive: Explain route loaders concept in depth.

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5738**

## Overview

Data-router loaders fetch before rendering resolving navigation-blocking data with pending UI states (useNavigation). Errors bubble to route errorElement boundaries. Loaders parallelize across matched routes eliminating waterfalls that sequential useEffect fetching creates.
