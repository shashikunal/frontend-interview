# What is scroll restoration handling?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5341**

## Overview

Browsers restore native scrolls on popstate but SPAs pushing history need ScrollRestoration component (router-provided) or manual effect saving positions keyed by location. New navigations scroll top; back/forward restore saved offsets. Animated transitions complicate restoration timing requiring post-transition correction.
