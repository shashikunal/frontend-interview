# What common mistakes do developers make with lazy initial state?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5065**

## Overview

Passing a function to useState defers expensive computation until first render only: useState(() => buildFromLocalStorage()). Without it the initializer runs every render wasting work even though result ignored after mount. Arguments to the lazy initializer cannot reference props safely before mount.
