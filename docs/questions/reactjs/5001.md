# Can you clearly articulate what React is?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5001**

## Overview

React is a JavaScript library for building declarative, component-based user interfaces. You describe UI as a function of state; React computes DOM updates efficiently via reconciliation. It handles the view layer only, leaving routing, data fetching and styling to ecosystem choices.
