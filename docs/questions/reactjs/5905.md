# Senior-level follow-up: Explain state vs props distinction in depth.

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5905**

## Overview

State is owned and mutable within a component triggering re-render on change; props are external immutable inputs. The mental test: data changing over time from user/server becomes state; data passed in stays prop. Derived values should be computed during render, not duplicated into state.
