# What does form actions and useActionState look like in practice, and when does it matter?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5374**

## Overview

<form action={serverOrClientFn}> submits progressively working sans JS; useActionState wraps actions capturing prevState returning state for messages/errors. Pending states arrive via useFormStatus inside submitting components. This stack replaces onSubmit-preventDefault choreography with platform-aligned ergonomics.

- Call-site binding
- Implicit, explicit, new, and default binding
