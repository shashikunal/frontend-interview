# What is nested routes and Outlet?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5311**

## Overview

Parent route components render <Outlet/> marking child slot, sharing layouts (nav, sidebar) across siblings. Params cascade: /users/:userId/posts/:postId accessible via useParams at any depth. Relative links resolve against current nesting simplifying refactors of path prefixes.
