# Quick check: what common mistakes do developers make with useReducer?

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5575**

## Overview

useReducer manages complex state transitions via reducer(nextState, action) purity plus dispatch stability across renders. Suits multi-field interdependent updates, undo stacks, and state machines. Dispatch identity never changes, making it safe for effect deps without useCallback wrapping.

## Key Concepts

- Array iteration methods
- Functional programming patterns
- Immutability considerations

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
