# Prepare a strong interview answer covering why index keys are dangerous.

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5030**

## Overview

With index keys, inserting at the top shifts every item’s identity: React patches each row’s content rather than moving nodes, so internal state (input values, checkboxes, animations) attaches to wrong rows. Stable ids preserve component instances correctly through mutations.
