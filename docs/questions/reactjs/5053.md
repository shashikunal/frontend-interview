# How would you describe functional setState updates to a teammate?

> **Category:** ReactJS | **Difficulty:** Medium | **Question #5053**

## Overview

When new state depends on previous, pass updater: setCount(c => c + 1). Batched event handlers both using stale closure count would overwrite; updaters queue applying sequentially on latest value. Always prefer functional form inside timers, subscriptions, async callbacks.
