# Interview scenario — how would you describe useLayoutEffect timing to a teammate?

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5810**

## Overview

useLayoutEffect fires synchronously after DOM mutations before browser paint, enabling measurement-then-mutation without flicker (tooltip positioning, scroll anchoring). Costs blocking paint — reserve for visual-critical measurements; SSR warns because layout effects never run server-side.
