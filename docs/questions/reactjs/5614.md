# Quick check: what does server state vs client state look like in practice, and when does it matter?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5614**

## Overview

Server state (API data) arrives cached/duplicated/stale — fundamentally unlike client-only UI state. React Query/SWR specialize: caching, background refetch, deduplication, pagination, optimistic updates. Treating server data as generic reducer state reimplements these poorly; adopt dedicated layers early.
