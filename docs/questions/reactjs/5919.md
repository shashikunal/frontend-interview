# Senior-level follow-up: What is stale closures in hooks?

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5919**

## Overview

Closures capture render-time values; callbacks registered once (event listeners, intervals) see frozen props/state. Fixes: functional updaters for state, refs mirroring latest values, correct dependency arrays recreating callbacks, or useSyncExternalStore for subscription correctness. Stale closure bugs dominate senior interviews.

## Key Concepts

- Lexical scoping
- Function returning function
- Captured variables

## Syntax & Examples

### Basic Closure

```javascript
function outer() {
  const secret = "hidden"
  return function inner() {
    return secret // accesses outer scope
  }
}

const getSecret = outer()
console.log(getSecret()) // "hidden"
```

Inner function retains access to outer function scope after outer returns.

### Closure in React (useState)

```javascript
function Counter() {
  const [count, setCount] = useState(0)

  const handleClick = () => {
    setCount(c => c + 1) // closure captures latest count
  }
  // ...
}
```

React hooks use closures to capture state values. Functional updates avoid stale closures.
