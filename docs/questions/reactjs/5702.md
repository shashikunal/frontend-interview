# Deep dive: What is forwardRef?

> **Category:** ReactJS | **Difficulty:** Hard | **Question #5702**

## Overview

forwardRef lets function components accept ref from parents forwarding to inner DOM/custom node, essential for reusable inputs, tooltips, portals. React 19 allows ref as regular prop for function components, but forwardRef remains needed for libraries supporting older versions simultaneously.
