# Quick check: explain JSX in depth.

> **Category:** ReactJS | **Difficulty:** Easy | **Question #5562**

## Overview

JSX is syntax sugar for React.createElement (or jsx runtime calls): expressions compile to plain objects describing elements. Attributes camelCase (className, onClick), children nest naturally. JSX must return a single root or Fragment, and {} embeds any expression including maps of elements.
