# What common mistakes do developers make with enums tradeoffs?

> **Category:** TypeScript | **Difficulty:** Medium | **Question #6080**

## Overview

Numeric enums reverse-map and auto-number risking surprise collisions; string enums serialize readably. Many teams prefer const-object + union-of-keys patterns avoiding enum emit quirks under isolatedModules. Enums remain valid choices for closed sets needing namespace-like grouping.
