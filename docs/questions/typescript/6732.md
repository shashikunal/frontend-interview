# Interview scenario — what is abstract classes typing role?

> **Category:** TypeScript | **Difficulty:** Hard | **Question #6732**

## Overview

Abstract classes declare unimplemented members enforcing subclass contracts while shipping shared implementation — midway between interfaces and concrete bases. Cannot instantiate directly. Prefer interfaces + composition generally; abstract bases justify themselves sharing real plumbing across siblings.
