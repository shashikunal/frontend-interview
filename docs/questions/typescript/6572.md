## Overview

Literal types restrict values to exact primitives ("left" | "right", 1 | 2). Combined with unions they replace enums for fixed vocabularies; as const captures object/array shapes as readonly literals powering config typing. Widening rules keep inference pragmatic in mutable contexts.
