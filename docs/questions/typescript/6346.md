# What is circular type references handling?

> **Category:** TypeScript | **Difficulty:** Easy | **Question #6346**

## Overview

Mutually recursive types (tree nodes, ASTs) work naturally; value-level circular imports complicate emission order occasionally. Interface indirection breaks cycles aliases cannot (aliases eagerly resolve). Lazy conditional types defer resolution sidestepping infinite expansion traps in pathological recursive generics.
