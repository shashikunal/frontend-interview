# Deep dive: How would you describe mapped types to a teammate?

> **Category:** TypeScript | **Difficulty:** Hard | **Question #6586**

## Overview

[K in keyof T]: ... transforms every key systematically — Readonly, Partial are built-in exemplars. Key remapping via as clauses filters/renames (omit by exclusion, template-literal renames). Mapped types are the workhorse of generic API-shaping utilities in real codebases.

## Key Concepts

- Array iteration methods
- Functional programming patterns
- Immutability considerations

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
