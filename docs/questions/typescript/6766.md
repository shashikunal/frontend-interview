# Senior-level follow-up: Explain readonly modifiers in depth.

> **Category:** TypeScript | **Difficulty:** Medium | **Question #6766**

## Overview

readonly forbids property reassignment (compile-time only) and Readonly<T>/ReadonlyArray<T> freeze views of data. Functions declaring readonly params promise non-mutation enabling safe shared-state passing. Deep immutability needs recursive mapped types or libraries since readonly is shallow.

- Promise states: pending, fulfilled, rejected
