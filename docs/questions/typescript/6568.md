# Deep dive: What common mistakes do developers make with void vs undefined return?

> **Category:** TypeScript | **Difficulty:** Easy | **Question #6568**

## Overview

void means callers should not use the return value (though undefined flows through); explicit undefined demands returning it. Callbacks typed void permit any-returning implementations safely (return values ignored) — why Array.forEach callbacks may return mapped values harmlessly.
