# What is reducer action typing?

> **Category:** TypeScript | **Difficulty:** Easy | **Question #6241**

## Overview

Discriminated union Actions with payload per kind; reducer switch exhaustively narrows accessing payload safely; never-type default catches unhandled cases at compile time. Export action creators typed individually. This trio (unions/exhaustive-switch/creators) defines robust reducer contracts.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
- Array iteration methods
- Functional programming patterns
- Immutability considerations

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
