# Senior-level follow-up: What common mistakes do developers make with function overloads?

> **Category:** TypeScript | **Difficulty:** Easy | **Question #6789**

## Overview

Overload signatures list call shapes preceding one implementation resolving dynamically. Prefer union params/generics when possible; overloads earn complexity with genuinely divergent returns per input shape (createElement variants, date parsers). Implementation signature stays invisible to callers.
