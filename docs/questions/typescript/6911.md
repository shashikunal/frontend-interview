# Rapid fire: what does namespace vs module history look like in practice, and when does it matter?

## Overview

Namespaces (global IIFE grouping) predate ES modules — legacy codebases and ambient declarations still use them. New code uses ES modules exclusively; namespaces survive legitimately in d.ts organizing large ambient APIs. Migrating namespaces→modules proceeds incrementally file-by-file.
