# Whiteboard prompt: How would you describe template literal types to a teammate?

> **Category:** TypeScript | **Difficulty:** Medium | **Question #6963**

## Overview

Template literal types concatenate string types enforcing formats: `${K}-${number}` validates event names/routes at compile time. Combined with key remapping they generate derived key names (getters, setters). Regex-literal types (TS 5.5+) narrow via pattern matching inference.
