# Phone screen edition: what does generators look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3452**

## Overview

Generator functions (function*) yield multiple values lazily and pausably; each next() resumes until the next yield. They implement custom iterators, infinite sequences, and cooperative control flow. yield* delegates to another iterable. Generators underpinned early redux-saga effects and remain useful for streaming pipelines.
