# Explain for...of vs for...in in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #392**

## Overview

for...of iterates values of iterables (arrays, strings, maps) respecting insertion order; for...in enumerates string keys including inherited enumerable ones, historically meant for objects. Using for...in on arrays yields indices as strings and prototype noise. Default to for...of for collections and Object.entries for object data.
