# Onsite panel edition: What does AbortController look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3785**

## Overview

AbortController pairs a signal with cancellable operations: pass signal into fetch or event listeners, then abort() rejects with AbortError named reason. React effects abort stale requests preventing race-condition state overwrites. Reuse one controller to cancel many operations, and always distinguish user-cancellations from real errors in catch blocks.
