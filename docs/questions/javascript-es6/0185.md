# What common mistakes do developers make with microtasks vs macrotasks?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #185**

## Overview

Microtasks (promise callbacks, queueMicrotask, MutationObserver) drain completely after each macrotask and between script segments. Macrotasks (setTimeout, setInterval, I/O, UI events) run one per loop turn. Therefore Promise.then fires before setTimeout(0) even when registered later, a classic interview output-ordering question.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
