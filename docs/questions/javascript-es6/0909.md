# What does delete operator behavior look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #909**

## Overview

delete removes own configurable properties returning boolean, leaving holes in arrays (length unchanged!) rather than compacting — use splice/filter for elements. Deleting non-configurable properties fails (false/falsey in strict mode throws). Hot paths suffer perf penalties since engines deoptimize shape caches after deletions.
