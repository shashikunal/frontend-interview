# Rapid fire: what common mistakes do developers make with fetch API essentials?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2932**

## Overview

fetch returns a promise resolving as soon as headers arrive — network failures reject, but HTTP 404/500 resolve OK-false, so check response.ok and status manually. Reading the body consumes it once via json()/text(). Configure credentials mode for cookies, AbortController for cancellation, and handle timeouts explicitly since fetch lacks a built-in timeout.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
