# Quick check: what common mistakes do developers make with Object.freeze?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4277**

## Overview

Object.freeze makes an object shallowly immutable: existing properties become non-writable and non-configurable, and no new ones can be added. Nested objects remain mutable, so deep freezing requires recursion. In non-strict mode writes fail silently; in strict mode they throw. Frozen objects signal intent and help with immutability patterns.
