# Interview scenario — how would you describe method chaining design to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2434**

## Overview

Fluent APIs chain methods by returning this (or new immutable instances) after each operation, producing declarative pipelines: query.select().where().limit(). Mutable-this chaining couples calls dangerously under shared state; immutable chaining (returning copies) suits concurrent contexts like string/array methods and state libraries.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
