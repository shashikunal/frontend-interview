# What is cache strategies in service workers?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1366**

## Overview

Strategies match resource temperament: cache-first for hashed assets (immutable), network-first for HTML/API freshness, stale-while-revalidate balancing speed/update, cache-only for offline shells. Workbox expresses these declaratively with expiration/broadcast plugins. Wrong strategy manifests as stuck old UI or needless data churn.
