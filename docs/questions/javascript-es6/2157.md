# Deep dive: What does this in event handlers look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2157**

## Overview

Traditional function handlers receive this === currentTarget element; arrow-function class properties capture surrounding instance instead — convenient for React classes, confusing for vanilla DOM where you lose element context. Inline arrow wrappers preserve both needs: el.addEventListener("click", () => this.handleClick(e)).

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this

## Syntax & Examples

### this Binding Rules

```javascript
// Default binding
function foo() { console.log(this) }
foo() // window (or undefined in strict)

// Implicit binding
const obj = { foo: function() { console.log(this) } }
obj.foo() // obj

// Explicit binding
foo.call(obj) // obj

// new binding
new foo() // new instance

// Arrow function (lexical)
const arrow = () => console.log(this)
arrow() // enclosing scope's this
```

this is determined by how a function is called (call-site), not where it's defined. Arrow functions inherit this lexically.
