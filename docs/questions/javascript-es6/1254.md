# What does continuation-passing style basics look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1254**

## Overview

CPS passes "what happens next" as continuation argument instead of returning — the conceptual basis of callbacks and how compilers transform async. Understanding CPS demystifies promise chaining as CPS sugar and clarifies why early returns cannot escape asynchronous boundaries.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
