# Interview scenario — what does template literals look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4852**

## Overview

Template literals use backticks, support multi-line strings, and interpolate expressions with ${}. Tagged templates pass pieces and substitutions to a function, powering libraries like styled-components and gql. They preserve whitespace exactly and escape backticks with a backslash.
