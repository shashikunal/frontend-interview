# Rapid fire: what does pure functions look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2881**

## Overview

Pure functions return identical outputs for identical inputs and cause no observable side effects, making them trivially testable, cacheable, and parallelizable. JavaScript purity is convention: watch hidden inputs like Date.now, Math.random, globals, DOM, and mutated parameters. Impurity concentrated at boundaries keeps cores predictable.
