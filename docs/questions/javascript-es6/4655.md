# Deep dive: What common mistakes do developers make with string padding and trimming methods?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4655**

## Overview

padStart/padEnd pad to target length with optional filler (default spaces) — perfect for aligning output and zero-filling ids. trimStart/trimEnd (plus alias trimLeft/right) remove edge whitespace. All return new strings since strings are immutable. repeat(n) builds repeated segments cheaply.
