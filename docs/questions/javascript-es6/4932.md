# Interview scenario — what does let in for loops look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4932**

## Overview

let creates a per-iteration binding, so closures inside the loop body capture distinct copies of the counter — fixing the classic setTimeout-printing-5 bug without IIFEs. The update expression runs between iterations copying into the fresh binding, which is why break/continue semantics stay intuitive.
