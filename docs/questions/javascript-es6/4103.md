# Hiring manager edition: what does WeakRef and FinalizationRegistry look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4103**

## Overview

WeakRef holds a weak reference queried via deref(), letting caches observe liveness without pinning memory; FinalizationRegistry schedules callbacks after collection. Both are advanced GC-cooperative tools with no guarantees about timing — never rely on finalizers for correctness, only opportunistic cleanup like cache pruning.
