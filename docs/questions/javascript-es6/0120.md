# What common mistakes do developers make with structuredClone?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #120**

## Overview

structuredClone performs native deep cloning supporting cyclical structures, Map, Set, Date, RegExp, ArrayBuffer and typed arrays, while throwing on functions, DOM nodes, and property descriptors. It avoids JSON.stringify pitfalls and the slow JSON round-trip hack, making it the default choice for deep-copying data objects.
