# Deep dive: What common mistakes do developers make with object shorthand and computed properties?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4650**

## Overview

ES6 lets { name } stand in for { name: name }, and computed keys [expr] evaluate dynamic property names at literal creation: { [`${prefix}Id`]: 1 }. Together they slim config/factory code dramatically. Computed keys cannot appear in destructuring patterns with variables on the left.
