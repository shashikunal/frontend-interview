# Whiteboard prompt: Explain dynamic import in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3187**

## Overview

import("./mod") returns a promise resolving to the module namespace, letting you load code conditionally, lazily, or after user interaction. Bundlers split dynamic imports into separate chunks automatically, forming the basis of route-based code splitting. Handle rejection for offline/error states.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
