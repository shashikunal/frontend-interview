# Senior-level follow-up: What common mistakes do developers make with Server-Sent Events vs WebSockets?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2774**

## Overview

SSE is unidirectional HTTP streaming with auto-reconnect built-in, text-only, trivial through proxies — ideal feeds/notifications. WebSockets provide bidirectional binary messaging needing heartbeat/reconnect/queueing layers. Choose SSE when clients merely listen; sockets for chat/collaboration interactivity.
