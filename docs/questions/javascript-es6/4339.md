# Quick check: explain sort mutability and comparator in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4339**

## Overview

Array.sort sorts in place and returns the same array; default comparison converts to strings, so 10 sorts before 9. Provide (a,b)=>a-b for numbers and localeCompare or Intl.Collator for strings. ES2019 mandates stable sort, preserving relative order of equal elements. Use toSorted for non-mutating copies.
