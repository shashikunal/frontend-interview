> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4018**

## Overview

Immutability treats data as unchangeable; updates create new values instead of mutating. It prevents aliasing bugs and enables change detection by reference equality, which React relies on. Tools range from spread and structuredClone to Immer’s draft proxies and Object.freeze enforcement in development.
