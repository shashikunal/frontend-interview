# Interview scenario — how would you describe default parameter evaluation order to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2439**

## Overview

Defaults evaluate left-to-right and may reference earlier params: function f(a, b = a * 2). Each call recomputes expressions — including side-effectful factory calls — so keep defaults pure or memoized. Accessing later params in earlier defaults throws TDZ ReferenceError, mirroring let semantics.
