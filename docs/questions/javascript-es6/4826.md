# Interview scenario — how would you describe hoisting to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4826**

## Overview

Hoisting is the engine moving declarations to the top of their scope during the creation phase of an execution context. Function declarations are fully initialized, var gets undefined, let/const stay in the temporal dead zone until evaluation. Class declarations are also in a TDZ. Understanding hoisting explains why calling code before its declaration sometimes works and sometimes throws.
