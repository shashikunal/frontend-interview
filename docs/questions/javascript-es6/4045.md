# Hiring manager edition: what is string immutability?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4045**

## Overview

Strings are immutable primitives: every "modification" method returns a new string, and indexing assignment silently fails (strict mode throws). This guarantees safe sharing and enables interning optimizations. Heavy concatenation in loops should use arrays plus join or template accumulation to avoid quadratic copying.
