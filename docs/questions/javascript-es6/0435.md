# What common mistakes do developers make with Array.from and Array.of?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #435**

## Overview

Array.from converts array-likes (arguments, NodeList) and iterables to arrays, optionally mapping during conversion — handy for range generation: Array.from({length:n},(_,i)=>i). Array.of wraps arbitrary values into an array, fixing new Array(3) hole weirdness. Both respect custom iterables and this-mapping receivers.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
