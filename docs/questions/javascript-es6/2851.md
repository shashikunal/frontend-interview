# Rapid fire: what does ES6 classes look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2851**

## Overview

Classes are syntactic sugar over prototypes with stricter semantics: bodies run in strict mode, declarations are not hoisted usable before definition, methods are non-enumerable, and calling without new throws. They support extends, super, getters/setters, static methods, static blocks, and private #fields. Under the hood instances still delegate through [[Prototype]].

## Key Concepts

- Prototype chain
- Object.create()
- Constructor functions
