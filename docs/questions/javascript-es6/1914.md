# Quick check: what does async error propagation look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1914**

## Overview

Thrown errors inside async functions reject their returned promise; awaited rejections bubble like sync exceptions through try/catch. Unawaited async calls orphan errors — attach .catch immediately or use Promise.allSettled for batch tolerance. Global handlers (unhandledrejection event) catch strays for logging.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
