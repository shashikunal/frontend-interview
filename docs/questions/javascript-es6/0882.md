# Explain ASI semicolon insertion gotchas in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #882**

## Overview

Automatic semicolon insertion only inserts at line breaks when the next token cannot continue the statement, causing classic bugs: return\n{...} returns undefined, and lines starting with ( or [ join the previous expression. Formatters plus consistent explicit semicolons (or no-semicolons with leading-guard style) neutralize ASI surprises.
