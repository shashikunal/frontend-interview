> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4159**

## Overview

Each iframe/realm owns distinct globals and constructors, so [] from another realm fails Array.isArray-free instanceof checks. Cross-realm safe utilities: Array.isArray, Object.prototype.toString.call tags, duck typing, or structuredClone transfer. Libraries must avoid identity assumptions when operating on foreign-realm inputs.
