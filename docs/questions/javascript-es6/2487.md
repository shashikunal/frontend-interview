# Interview scenario — what is request deduplication?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2487**

## Overview

Dedup layers key concurrent identical GETs returning the shared in-flight promise, collapsing N simultaneous mounts into one network hit — React Query/SWR do this automatically. Manual maps store promise-by-key deleting on settle. Beware caching errors: failing shared promises should clear promptly allowing retries.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
