# Deep dive: What is getters and setters?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2004**

## Overview

Accessor properties intercept reads and writes through get/set functions, enabling computed values, validation, and logging while keeping call-site syntax natural. Defined in object literals, classes, or defineProperty. Overusing them hides side effects behind innocent-looking assignment, so keep them cheap and side-effect free.
