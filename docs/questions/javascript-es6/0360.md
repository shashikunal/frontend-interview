# What common mistakes do developers make with parseInt and parseFloat?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #360**

## Overview

parseInt stops at the first non-digit, ignores leading whitespace, accepts signs and radix; always pass radix 10 to avoid legacy octal interpretations ("08" once parsed as 0). parseFloat handles decimals and exponents similarly stopping early. For strict validation prefer Number(), which returns NaN on any residue.
