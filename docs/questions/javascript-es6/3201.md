# Whiteboard prompt: What is Array.filter and find?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3201**

## Overview

filter keeps elements passing the predicate into a new array; find returns the first match or undefined, short-circuiting early. findIndex, findLast and findLastIndex extend the family. Choosing find over filter[0] communicates intent and avoids scanning the whole collection.

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
