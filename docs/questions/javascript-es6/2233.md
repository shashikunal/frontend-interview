# Deep dive: What common mistakes do developers make with hydration mismatch debugging?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2233**

## Overview

Mismatches arise from Date.now/random rendering, locale-dependent formatting, invalid HTML nesting (p>div auto-correction), or conditional browser extensions mutating markup pre-hydration. Suppress via useEffect-time client-only values, suppressHydrationWarning sparingly, and validate server HTML determinism in CI snapshots.
