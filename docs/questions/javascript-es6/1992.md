# Deep dive: What does the this keyword look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1992**

## Overview

this refers to the context in which a function executes, determined by how it is called rather than where it is defined. Rules in priority order: new binding, explicit binding via call/apply/bind, implicit binding from the containing object at call site, and default binding (undefined in strict mode, global otherwise). Arrow functions ignore all these rules and lexically inherit this.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this

## Syntax & Examples

### this Binding Rules

```javascript
// Default binding
function foo() { console.log(this) }
foo() // window (or undefined in strict)

// Implicit binding
const obj = { foo: function() { console.log(this) } }
obj.foo() // obj

// Explicit binding
foo.call(obj) // obj

// new binding
new foo() // new instance

// Arrow function (lexical)
const arrow = () => console.log(this)
arrow() // enclosing scope's this
```

this is determined by how a function is called (call-site), not where it's defined. Arrow functions inherit this lexically.
