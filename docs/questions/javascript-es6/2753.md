## Overview

requestIdleCallback schedules low-priority work during idle periods (deadline.timeRemaining() guides chunking), ideal for analytics flushing, prefetch hints, non-urgent indexing. Fallback shim defers via setTimeout since Safari lagged support. Always timebox tasks yielding regularly so idle work never degrades interaction latency.
