# Phone screen edition: explain NaN quirks in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3475**

## Overview

NaN is the only value unequal to itself, so isNaN(NaN) is true while NaN === NaN is false. Global isNaN coerces its argument ("42" passes!), whereas Number.isNaN checks strict NaN identity. NaN arises from failed parses, invalid math (0/0, Math.sqrt(-1)), and undefined arithmetic — guard boundaries before math happens.
