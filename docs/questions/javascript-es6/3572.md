# Phone screen edition: what does primitive wrappers look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3572**

## Overview

Accessing properties on primitives auto-boxes them into temporary String/Number/Boolean objects discarded immediately, which is why (1).toFixed works yet storing new String("a") creates trouble (truthy object, typeof "object", == vs === surprises). Never instantiate wrappers manually; let coercion happen implicitly.
