# How would you describe testing async code to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1303**

## Overview

Await promises in assertions (test frameworks fail silently on floating assertions), flush microtask queues with awaits between steps, fake network via msw interceptors asserting request shapes, and test rejection paths explicitly with expect(...).rejects. Race-prone flakiness signals underspecified synchronization, fix scheduling rather than adding sleeps.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
