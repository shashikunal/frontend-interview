# Explain creating dictionary-safe objects in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #922**

## Overview

Object.create(null) yields prototype-less maps immune to key collisions ("constructor", "__proto__") and accidental inherited method calls, ideal for user-input-keyed dictionaries. JSON.parse output inherits normally, so sanitize or migrate to Map when keys come from untrusted sources. __proto__ setter attacks exploit literal-object prototypes.
