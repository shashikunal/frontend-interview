# What does dataset attributes bridging DOM state look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1019**

## Overview

data-* attributes expose camelCased via element.dataset (data-user-id → dataset.userId), carrying component state in markup for CSS hooks ([data-state="open"]) and delegated handlers reading targets. Strings only — parse numbers/JSON explicitly. Overuse turns DOM into database; keep authoritative state in JS.
