# Rapid fire: what does dependency injection in JavaScript look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3066**

## Overview

DI passes collaborators through constructors/factories instead of importing globals, unlocking substitution in tests and environment swaps (real vs mock fetch). Container libraries optional — plain parameter passing often suffices. Module mocking (jest.mock/vi.mock) offers alternative seam when refactor cost is high.
