# Rapid fire: what is callbacks?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2868**

## Overview

A callback is a function handed to another function for later invocation. Synchronous callbacks run inline (map); asynchronous ones run later via the event loop (setTimeout, fetch handlers). Deeply nested async callbacks produce pyramid-of-doom code, which Promises and async/await were designed to flatten.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Call stack
- Task queue (macrotasks)
- Microtask queue
- Event loop tick
