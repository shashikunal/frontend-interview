## Overview

Offline-first treats connectivity as enhancement: local database (IndexedDB) is source of truth, sync queues mutations replaying with conflict policies (last-write-wins, CRDTs for merges), UI reflects sync status honestly. Service workers cache app shell; background sync retries queued sends opportunistically.
