## Overview

Bundlers inline import.meta.env/VITE_* prefixed vars at build time — secrets leak into shipped JS, so backend proxies hold private keys. Runtime-configurable settings belong in served /config.json fetched at boot. Validate required vars at startup failing fast with clear messages rather than undefined-propagating mysteries.
