# Whiteboard prompt: How would you describe Set to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #3173**

## Overview

Set stores unique values of any type with O(1)-ish add/has/delete, preserving insertion order. Idiomatic deduplication: [...new Set(arr)]. Because uniqueness uses SameValueZero, NaN dedupes correctly. Sets beat filter/indexOf dedupe approaches asymptotically for large arrays.
