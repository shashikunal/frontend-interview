> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2232**

## Overview

Universal code runs both server and client: guard DOM/BOM access, avoid window-scoped caches leaking cross-request state, use platform-agnostic fetch (undici/node18+), and handle env config differences. Hydration expects deterministic renders — randomness/time must serialize identically or gate behind effects.
