# What does factory functions vs constructors look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #804**

## Overview

Factories return plain objects built however you like — no new keyword, easy composition, private state via closures — while constructors/classes share prototypes saving memory across many instances and enabling instanceof polymorphism. Choose factories for varied shapes/one-offs, classes for large homogeneous populations.
