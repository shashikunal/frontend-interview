# What is function.length property?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #821**

## Overview

function.length reports parameter count before the first default/rest parameter — useful for arity-based dispatch, argument validation, and library APIs adapting behavior. Changing signatures alters length, so code depending on it breaks silently during refactors; treat as informational metadata rather than contract.
