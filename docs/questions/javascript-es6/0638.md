> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #638**

## Overview

import.meta exposes module-scoped metadata: url (file location), resolve(specifier) for URL resolution, plus bundler extensions like env in Vite. Unlike process/env globals it works in browsers natively. Useful for asset path building, feature flags injection, and worker construction relative to module URL.
