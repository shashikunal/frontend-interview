# Rapid fire: explain Object.groupBy and Map.groupBy in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2974**

## Overview

Grouping helpers partition collections by callback key: Object.groupBy(users, u => u.role) returns null-prototype object; Map.groupBy allows non-string keys. They retire hand-rolled reduce grouping boilerplate and pair well with flatMap for multi-key membership scenarios.

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
