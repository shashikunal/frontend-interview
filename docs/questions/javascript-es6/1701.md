# Quick check: what is the difference between var, let and const?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1701**

## Overview

var is function-scoped, hoisted with an initial value of undefined, and attaches to the global object at top level. let and const are block-scoped, hoisted but uninitialized (temporal dead zone), and do not attach to window. const forbids reassignment but allows mutation of object contents. Modern code defaults to const and uses let only when reassignment is required.

## Key Concepts

- Function scope vs block scope
- Hoisting behavior
- Temporal Dead Zone (TDZ)

## Syntax & Examples

### var - Function Scoped

```javascript
function example() {
  if (true) {
    var x = 10
  }
  console.log(x) // 10 - accessible outside block
}
```

var is function-scoped, not block-scoped.

### let/const - Block Scoped

```javascript
function example() {
  if (true) {
    let y = 10
    const z = 20
  }
  console.log(y) // ReferenceError
  console.log(z) // ReferenceError
}
```

let and const are block-scoped, limited to the {} block.

### Hoisting Differences

```javascript
console.log(a) // undefined (hoisted)
var a = 5

console.log(b) // ReferenceError (TDZ)
let b = 5
```

var is hoisted and initialized with undefined. let/const are hoisted but uninitialized (TDZ).

## Additional Examples

### Loop Variable Capture

```javascript
// PROBLEM with var
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100)
}
// Logs: 3, 3, 3

// SOLUTION with let
for (let i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100)
}
// Logs: 0, 1, 2
```

var creates one shared variable. let creates a new binding per iteration.
