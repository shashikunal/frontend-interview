# What common mistakes do developers make with mutation hazards in shared state?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #850**

## Overview

Aliased mutations cause spooky action at a distance: two variables referencing one array see each other’s pushes/sorts. Copy before mutate (slice/spread/structuredClone) or adopt immutable update discipline. Bugs cluster around sort/splice/reverse because they mutate in place while looking innocent.
