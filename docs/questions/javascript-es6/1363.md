# How would you describe service worker lifecycle to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1363**

## Overview

SWs install (precache), wait until old clients close unless skipWaiting forces activation, controlling page only after claim/reload — versioned caches enable atomic swaps. Update flows detect registration.update, activate new SW, message clients to reload. Misconfigured lifecycles cause infamous stale-asset ghosts.
