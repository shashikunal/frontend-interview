# Phone screen edition: how would you describe clamp/random utility functions to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3601**

## Overview

Clamp constrains values: Math.min(Math.max(v, lo), hi) — essential for sliders, pagination indices. Random ranges: lo + Math.random()*(hi-lo); integer variants floor appropriately; crypto.getRandomValues for security contexts since Math.random is not cryptographically secure. Fisher-Yates shuffles arrays uniformly.
