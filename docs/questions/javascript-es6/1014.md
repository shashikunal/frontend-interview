# What does innerHTML vs textContent security look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1014**

## Overview

textContent inserts escaped text safely; innerHTML parses markup executing scripts/event-handler attributes embedded in unsanitized input — the XSS vector. Sanitize with DOMPurify when HTML is required, prefer textContent/createElement otherwise. Template engines escape by default; raw-output escapes hatches bypass that protection.
