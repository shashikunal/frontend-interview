## Overview

BigInt represents arbitrary-precision integers via suffix n or BigInt(); arithmetic requires both operands BigInt (mixing Number throws), division truncates toward zero, and Math methods do not accept it. JSON needs manual string serialization. Perfect for crypto tokens, 64-bit ids, and exact integer math beyond 2^53.
