# Explain async generators in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #627**

## Overview

async function* yields promises consumed sequentially by for-await loops, enabling lazy pipelines over time-based or network sources: reading NDJSON lines, polling until condition, consuming SSE. Each next() returns a promise; combining yield with await interleaves production and IO naturally.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
