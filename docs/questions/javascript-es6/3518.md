# Phone screen edition: what common mistakes do developers make with array destructuring tricks?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3518**

## Overview

Skip holes to ignore elements: const [, second] = arr. Swap without temp: [a, b] = [b, a]. Collect tails with rest: const [head, ...tail] = arr. Defaults pair with undefined only. These idioms replace verbose index juggling and read like pattern-matching from functional languages.
