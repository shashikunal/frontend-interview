> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4406**

## Overview

Defining Symbol.toPrimitive(hint) controls object conversion for string/number/default hints, overriding valueOf/toString ordering. Libraries use it for money/date formatting inside template literals and arithmetic. Returning primitives keeps operators predictable; returning objects triggers TypeError, enforcing correctness.
