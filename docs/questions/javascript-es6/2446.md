# Interview scenario — what common mistakes do developers make with bitwise operators are 32-bit?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2446**

## Overview

All bitwise ops coerce operands to signed 32-bit integers, silently truncating larger numbers and NaN→0 — handy for fast floor (|0), hashing, flags; dangerous for big values and ids. >>> treats operands unsigned. Prefer Math.floor for clarity unless bit-twiddling performance genuinely matters.
