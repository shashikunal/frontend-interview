# Quick check: what does event bubbling and capturing look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4346**

## Overview

DOM events propagate capturing downward, hit the target, then bubble upward. Listeners default to bubble phase; capture:true engages the descent. stopPropagation halts travel; stopImmediatePropagation also silences sibling listeners on the same node. Understanding phases underpins delegation and overlay-close-outside-click logic.
