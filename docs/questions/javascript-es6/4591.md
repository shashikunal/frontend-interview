# Deep dive: What is Map vs plain object?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4591**

## Overview

Map accepts any key type, preserves insertion order, exposes size, iterates directly, and performs better under frequent add/delete churn. Plain objects suit fixed schemas, JSON interchange, and structural patterns. WeakMap holds keys weakly for metadata attachment without preventing garbage collection.

## Key Concepts

- Array iteration methods
- Functional programming patterns
- Immutability considerations

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
