# Phone screen edition: what common mistakes do developers make with URL encoding pitfalls?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3688**

## Overview

encodeURIComponent escapes component-safe (slashes become %2F) versus encodeURI preserving structural characters — mixing them corrupts URLs. Plus signs mean space only in form-encoding contexts. URLSearchParams encodes correctly per spec; hand-rolling invites broken queries containing ampersands/unicode emoji.
