# Quick check: what does matchAll for global regex results look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4391**

## Overview

matchAll(/pattern/g) returns an iterator of match objects including named groups and indices, unlike match with g flag which returns plain substrings only. Because it clones regex state, lastIndex pollution disappears. Loop with for...of or spread into arrays for structured scraping tasks.
