# Deep dive: What is arrow functions?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #1994**

## Overview

Arrow functions have lexical this (inherited from the enclosing scope), no own arguments object, cannot be used as constructors, and lack a prototype property. They shine as short callbacks where you want the surrounding this. They are wrong choices for object methods needing dynamic this, event handlers relying on this === currentTarget, or prototype methods.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
- Prototype chain
- Object.create()
- Constructor functions
