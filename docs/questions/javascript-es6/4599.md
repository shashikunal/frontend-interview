# Deep dive: What does optional chaining look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4599**

## Overview

Optional chaining (a?.b, a?.[k], fn?.()) short-circuits to undefined when the left side is null or undefined, avoiding TypeError walls. It composes with ?? for defaults: user?.address?.city ?? "Unknown". Note short-circuit skips subsequent property accesses and calls entirely, and assigning to the result is illegal.
