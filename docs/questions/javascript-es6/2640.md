# Senior-level follow-up: What is sparse arrays and holes?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2640**

## Overview

Deleting elements or new Array(3) creates holes skipped by forEach, map preserves them, and join renders empty strings, causing inconsistent iteration behavior. Avoid holes: use fill, splice, or filter(Boolean) normalization. length truncation (arr.length=0) clears arrays cheaply and deliberately.
