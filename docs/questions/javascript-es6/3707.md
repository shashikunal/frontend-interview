# Onsite panel edition: What is property descriptors?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3707**

## Overview

Every property has a descriptor containing value, writable, enumerable, and configurable (plus get/set for accessors). Object.defineProperty creates or mutates them; Object.getOwnPropertyDescriptor inspects them. Non-enumerable properties hide from for-in and Object.keys; non-configurable properties can never be deleted or reconfigured.
