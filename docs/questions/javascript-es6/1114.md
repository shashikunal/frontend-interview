# What does WebSocket reconnection discipline look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1114**

## Overview

Robust socket clients implement exponential-backoff reconnect with jitter, message buffering during disconnection, heartbeats detecting half-open connections, and state resync (fetch missed deltas) after restore. Treat the wire as unreliable — application-level acks confirm critical deliveries.
