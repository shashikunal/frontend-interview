# Whiteboard prompt: How would you describe shadow DOM styling implications to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3398**

## Overview

Shadow boundaries isolate styles both ways: outer CSS misses inner elements; inheritable properties (color, font) pierce through. CSS custom properties and ::part() provide sanctioned theming channels. Constructable stylesheets enable shared performant style reuse across many shadow roots.
