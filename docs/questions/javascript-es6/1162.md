# Explain singleton pattern caveats in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1162**

## Overview

Singletons (module-scope instances, static getInstance) simplify access but hide dependencies, complicate testing resets, and smuggle mutable global state across imports. ESM modules are natural singletons anyway. Prefer explicit injection; reserve true singletons for genuine app-wide services (config loaders, telemetry clients).
