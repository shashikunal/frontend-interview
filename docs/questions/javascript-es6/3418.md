# Phone screen edition: what common mistakes do developers make with prototype chain?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3418**

## Overview

When reading a property, the engine checks the object itself, then its prototype, then that prototype’s prototype, until reaching null. Assignments create own properties instead of walking the chain. Object.getPrototypeOf reads the link safely, and hasOwnProperty (or Object.hasOwn) distinguishes own properties from inherited ones.
