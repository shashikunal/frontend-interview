# Quick check: what is immutability performance costs?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1926**

## Overview

Structural sharing (persistent data structures) makes immutable updates cheap despite copies; naive deep clones cost O(n) per change. Immer’s proxies copy-on-write only touched paths. Measure before assuming — small states copy trivially, huge nested stores benefit from normalization (flat entities by id).
