# What is method shorthand syntax?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #551**

## Overview

Object literals allow methods without the function keyword: { greet() {} }. These create regular functions (dynamic this), unlike arrow-property shorthand { greet: () => {} } whose this stays lexical — mixing them up breaks event handlers expecting instance context.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
