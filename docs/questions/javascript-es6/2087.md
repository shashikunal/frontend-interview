# Deep dive: What does ResizeObserver look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2087**

## Overview

ResizeObserver fires when an element’s box size changes — including container-driven layout shifts media queries cannot see — enabling chart redraws and container-responsive components. Callbacks receive contentRect/device-pixel sizes; beware observe-loops where resizing inside callback retriggers it (guard or debounce).
