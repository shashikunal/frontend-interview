# Hiring manager edition: what common mistakes do developers make with setTimeout in loops explained?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4144**

## Overview

setTimeout callbacks run after the loop completes, reading whatever the captured variable finally holds (var shares one binding → last value; let makes per-iteration bindings → sequential values). The event loop cannot interleave timer callbacks mid-loop because synchronous code always finishes first.
