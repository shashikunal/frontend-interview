# Interview scenario — explain stack safety with trampolines in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2518**

## Overview

Trampolining converts tail recursion into loops: recursive fn returns thunk; driver loop invokes until non-thunk result — eliminating stack growth for deep recursions on engines lacking TCO (all majors effectively). Useful for interpreters/parsers processing adversarially deep inputs.
