# Quick check: what is canvas basics versus SVG?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1911**

## Overview

Canvas raster-draws via immediate-mode 2D/WebGL contexts — fast for thousands of particles, pixel effects; SVG retains vector scene-graph enabling CSS animation, hit-testing per node, crisp zooming — better for icons/charts under hundreds of nodes. Hybrid apps draw canvas layers under SVG overlays capturing events.
