# Onsite panel edition: What is iterators and the iterator protocol?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3737**

## Overview

An iterator is any object with next() returning { value, done }. Iterables expose Symbol.iterator returning an iterator, unlocking for...of, spread, destructuring, and Array.from. Strings, arrays, maps, sets, NodeList are built-in iterables. Custom iterables integrate your structures seamlessly with language syntax.
