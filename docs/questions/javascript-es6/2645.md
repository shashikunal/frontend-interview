# Senior-level follow-up: What is custom events?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2645**

## Overview

CustomEvent with detail payload enables decoupled component communication through the DOM bus: dispatchEvent(new CustomEvent("cart:add", { detail, bubbles: true })). Listeners read event.detail. Useful for widget isolation and framework-free architecture; document the contract since types vanish at runtime.
