# Phone screen edition: what does Object.hasOwn look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3537**

## Overview

Object.hasOwn(obj, key) is the robust replacement for obj.hasOwnProperty() calls that break when objects lack the method or shadow it (Object.create(null), JSON-parsed weirdness). Static invocation avoids prototype dependence entirely, checking own enumerable and non-enumerable properties alike.
