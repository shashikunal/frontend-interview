# Onsite panel edition: Explain async/await in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3723**

## Overview

async functions implicitly return promises and pause at await without blocking the thread, resuming when the awaited promise settles. await unwraps thenables; awaiting non-thenables resolves immediately. Errors surface via try/catch. Sequential awaits inside loops often serialize requests unintentionally — Promise.all parallelizes independent work.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
