# Interview scenario — what does spread vs rest confusion look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2380**

## Overview

Same three dots, opposite directions: spread expands an iterable/object where values are consumed (calls, literals); rest collects remaining values into arrays/objects (params, destructuring). Position disambiguates: leading dots before a name in a parameter list mean gather; inline in arguments/literals mean expand.
