# Quick check: explain selector memoization patterns in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4484**

## Overview

Selectors derive view models from raw state cached by input references (reselect-style), recomputing only when dependencies change. Cheap reference checks gate expensive joins/sorts. Keep selectors pure and colocated near consumers; parametrized selectors use per-args memo caches keyed appropriately.
