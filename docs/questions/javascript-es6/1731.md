# Quick check: what is higher-order functions?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1731**

## Overview

A higher-order function takes functions as arguments or returns them. map, filter, reduce, debounce, once, and middleware chains are everyday examples. HOFs enable abstraction over behavior, composition, and separation of data from logic — the backbone of functional style in JavaScript.
