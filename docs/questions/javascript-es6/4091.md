# Hiring manager edition: explain numeric separators in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4091**

## Overview

Underscores improve numeric readability: 1_000_000, 0xFF_FF, 1_000n. They are purely syntactic sugar stripped during parsing, cannot lead/trail or sit adjacent to dots, and work in all numeric literal forms including BigInt. Ideal for constants like timeouts and magic thresholds.
