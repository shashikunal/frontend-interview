# Quick check: how would you describe memory leaks common causes to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1858**

## Overview

Top leak sources: forgotten setInterval/setTimeout without cleanup, detached DOM nodes retained in JS variables, ever-growing caches/maps keyed strongly, event listeners never removed, and closures capturing large scopes unnecessarily. Use WeakMap/WeakRef for metadata, clear timers on teardown, and profile heap snapshots comparing allocations over time.
