# Quick check: what common mistakes do developers make with tree shaking requirements?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #1940**

## Overview

Tree shaking removes unused exports only with ESM static structure, sideEffects:false declarations, and import paths avoiding namespace grabs (import * as). CommonJS defeats it dynamically. Verify via bundle analyzers; barrel files exporting everything can accidentally retain modules through side-effect ambiguity.
