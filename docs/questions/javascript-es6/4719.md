# Deep dive: What does unary plus and conversion tricks look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4719**

## Overview

+value converts to number faster than Number() and shorter than parseFloat, mapping strings, booleans (true→1), null→0, undefined→NaN. It fails visibly on malformed input returning NaN, making it decent strict parsing. Combined with Date it yields timestamps: +new Date() though Date.now() reads cleaner.
