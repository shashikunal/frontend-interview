# Senior-level follow-up: What common mistakes do developers make with Date handling gotchas?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2629**

## Overview

Date months are zero-indexed (0 = January) while days are one-indexed — a legendary trap. Parsing ISO-without-timezone treats it as local in some engines; date-only strings parse as UTC. Prefer Temporal (where available) or date-fns/dayjs; always store UTC, render local, and never do timezone math by hand.
