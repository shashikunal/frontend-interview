# Whiteboard prompt: Explain typeof operator pitfalls in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3177**

## Overview

typeof returns "object" for null (historic bug kept for compatibility), "function" for callables, and implementation-defined "unknown"/"xml" edge cases in old IE for undeclared vars. For reliable type detection combine typeof for primitives, Array.isArray for arrays, instanceof for classes, and Object.prototype.toString.call for exotic cases.
