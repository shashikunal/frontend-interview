# Hiring manager edition: explain structuredClone vs JSON round trip in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4111**

## Overview

JSON.parse(JSON.stringify(x)) mangles Dates to strings, drops undefined/functions/Symbol keys, converts NaN to null, and explodes on cycles. structuredClone preserves types, cycles, Maps/Sets/typed arrays, failing loudly on functions instead of silently corrupting. Default to structuredClone; fall back to JSON only for wire-format shaping.
