# Phone screen edition: explain thenable duck typing in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3620**

## Overview

Any object exposing then(resolve, reject) integrates with await/then machinery regardless of class origin — enabling lightweight task libraries without full Promise subclassing. Distinguish real promises via instanceof or util.types.isPromise; treat unknown thenables defensively since their resolution timing is contract-only.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
