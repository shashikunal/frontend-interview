# Senior-level follow-up: What is queueMicrotask?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2700**

## Overview

queueMicrotask schedules a callback onto the microtask queue directly — earlier than setTimeout macrotasks, after current synchronous code — useful for deferring to post-sync phase while keeping ordering deterministic relative to promise reactions. Cheaper than setTimeout(0) and immune to clamp delays.
