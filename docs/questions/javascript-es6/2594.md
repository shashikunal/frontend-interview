# Senior-level follow-up: What common mistakes do developers make with partial application?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2594**

## Overview

Partial application fixes some arguments ahead of time, returning a function accepting the remainder — unlike curry, it does not enforce one-argument-at-a-time. Function.prototype.bind is the built-in partial applier. It reduces repetition when many calls share leading arguments such as configuration or context.
