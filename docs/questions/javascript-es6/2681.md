## Overview

Proxy wraps targets intercepting fundamental operations (get, set, has, deleteProperty, apply...) through handler traps, powering validation layers, reactive frameworks (Vue 3), negative array indices shims, and logging. Revocable proxies sever access later. Traps must forward invariants or throw TypeError, keeping engine guarantees intact.
