## Overview

ESM tolerates cycles via live bindings — accessing not-yet-initialized bindings during evaluation throws TDZ errors, making cycle direction matter. Break cycles extracting shared logic into leaf modules, inverting dependencies via callbacks/events, or deferring requires lazily inside functions. Circular imports usually signal design smell.
