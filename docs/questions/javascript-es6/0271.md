# What is type coercion rules?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #271**

## Overview

Coercion converts operands when types mismatch: addition prefers string concatenation if either operand is a string; other arithmetic forces numbers; abstract equality applies ToPrimitive recursively. Knowing ToPrimitive (valueOf then toString) and ToBoolean (falsy list) defuses most == puzzles and clarifies why "5" - 3 is 2 but "5" + 3 is "53".
