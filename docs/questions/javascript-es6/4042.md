# Hiring manager edition: how would you describe Number safe integer range to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4042**

## Overview

Integers above Number.MAX_SAFE_INTEGER (2^53 - 1) lose precision silently because doubles allocate bits to exponent. Use BigInt (append n) for ids from databases or crypto contexts that exceed this range, remembering BigInt cannot mix with Number in arithmetic and JSON serializes it as string manually.
