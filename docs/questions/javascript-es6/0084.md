# What does static methods and properties look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #84**

## Overview

Static members belong to the class itself, not instances, and are inherited by subclasses through the class’s internal prototype chain. They commonly host factories, utilities, and cached config. Calling them on an instance throws because instances do not link to the constructor function.

- Prototype chain
- Object.create()
- Constructor functions
