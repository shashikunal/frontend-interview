# Explain const objects and mutation in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #542**

## Overview

const freezes the binding, not the value: properties of a const object can be added/deleted/changed freely; only reassignment throws. To achieve real immutability combine const with Object.freeze (shallow) or recursive deep-freeze. This distinction is a favorite trick question because intuition says const means constant.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
