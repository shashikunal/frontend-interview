# Interview scenario — what is debounce?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2307**

## Overview

Debouncing postpones invoking a function until a quiet period elapses since the last call, resetting a timer on every trigger. Ideal for search inputs, resize handlers, and autosave. Implementation stores the timer id in a closure and clearTimeouts it each invocation, optionally firing immediately on the leading edge.
