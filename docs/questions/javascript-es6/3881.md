# Onsite panel edition: What common mistakes do developers make with promisify conversion pattern?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #3881**

## Overview

Wrapping callback-style APIs: const promisify = fn => (...args) => new Promise((res, rej) => fn(...args, (err, data) => err ? rej(err) : res(data))). Node util.promisify ships production-grade handling including multi-args and symbols. Modern Node fs/promises shows ecosystem-wide migration results.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
