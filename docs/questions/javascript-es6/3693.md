# Onsite panel edition: Explain closures in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3693**

## Overview

A closure is a function that keeps a reference to the lexical environment where it was created, so it can access outer variables even after the outer function has returned. Closures power data privacy, callbacks, currying, memoization caches, and module patterns. They keep captured variables alive, which can also cause memory leaks if references outlive their usefulness.

## Key Concepts

- Lexical scoping
- Function returning function
- Captured variables

## Syntax & Examples

### Basic Closure

```javascript
function outer() {
  const secret = "hidden"
  return function inner() {
    return secret // accesses outer scope
  }
}

const getSecret = outer()
console.log(getSecret()) // "hidden"
```

Inner function retains access to outer function scope after outer returns.

### Closure in React (useState)

```javascript
function Counter() {
  const [count, setCount] = useState(0)

  const handleClick = () => {
    setCount(c => c + 1) // closure captures latest count
  }
  // ...
}
```

React hooks use closures to capture state values. Functional updates avoid stale closures.
