# Whiteboard prompt: What common mistakes do developers make with mocking time in tests?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3380**

## Overview

Fake timers (vi.useFakeTimers/jest) control setTimeout/Date deterministically, advancing virtually to test debounce/throttle/expiry without real waits. Restore after each test preventing bleed. For date-sensitive logic prefer injecting clock/clockNow params — simpler than global fakes and immune to timer-library drift.
