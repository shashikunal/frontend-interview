# How would you describe falsy values to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #278**

## Overview

Exactly six values coerce to false: false, 0, -0, 0n, "", null, undefined and NaN — everything else including [], {} and "0" is truthy. This trips developers checking presence with if(arr.length) versus if(arr). Nullish coalescing and optional chaining exist precisely to narrow checks to null/undefined only.
