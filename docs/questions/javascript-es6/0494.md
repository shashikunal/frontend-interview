# What does Web Workers look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #494**

## Overview

Web Workers run scripts on background threads communicating via postMessage structured-clone messaging, keeping heavy computation (parsing, image processing, crypto) off the main thread so UI stays responsive. No DOM access; importScripts or module workers allowed. SharedArrayBuffer plus Atomics enable zero-copy shared memory when COOP/COEP headers permit.
