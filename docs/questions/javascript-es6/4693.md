# Deep dive: How would you describe getter/setter in class inheritance to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4693**

## Overview

Overriding only a getter while parent defines setter (or vice versa) silently drops half the accessor pair unless you redefine both — accessors live on prototypes as units. super.x reads route through parent getters. Document paired accessors and prefer fields + explicit methods when asymmetric logic appears.
