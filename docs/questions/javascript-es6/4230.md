# Hiring manager edition: what is source maps fundamentals?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4230**

## Overview

Source maps map minified positions back to originals enabling readable stack traces; generate in build, upload privately to error trackers, avoid shipping publicly (exposes source). Browser devtools load linked .map automatically. Version-pin maps to exact deploys or traces misalign post-release.

## Key Concepts

- Array iteration methods
- Functional programming patterns
- Immutability considerations

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
