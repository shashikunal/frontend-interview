# Whiteboard prompt: What does floating point precision look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #3189**

## Overview

JavaScript numbers are IEEE-754 doubles, so 0.1 + 0.2 === 0.300000004... fails exact comparison and 0.1+0.2 prints 0.30000000000000004. Compare within epsilon, scale integers for money (or use BigInt minor units / decimal libraries), and format with toFixed/Intl.NumberFormat for display only.
