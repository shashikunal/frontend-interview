# Whiteboard prompt: What common mistakes do developers make with adapter and facade utilities?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3355**

## Overview

Adapters translate incompatible interfaces (normalizing vendor response shapes into internal DTOs); facades simplify subsystem clusters behind one ergonomic entry (api.get wrapping auth+retry+parse). Both isolate third-party churn at boundaries — swap payment providers by rewriting one adapter, not forty call sites.
