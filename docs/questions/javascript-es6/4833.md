# Interview scenario — what common mistakes do developers make with call, apply and bind?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4833**

## Overview

call invokes a function with a given this and arguments listed individually; apply does the same but takes arguments as an array; bind returns a new permanently-bound function without invoking it. Use call/apply for borrowing methods or variadic forwarding, bind for callbacks and event handlers that need stable context.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
