# What is class expression and mixin patterns?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #766**

## Overview

Classes are expressions too, enabling anonymous subclasses and mixins: const Mixin = Base => class extends Base { ... }; class Foo extends Mixin(Bar). Compose behaviors horizontally avoiding diamond problems of multiple inheritance. Keep mixins state-light and interface-narrow to prevent hidden coupling.
