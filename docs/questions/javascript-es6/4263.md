# Quick check: what is IIFE?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4263**

## Overview

An immediately invoked function expression is a function executed as soon as it is defined: (function () { ... })(). Before ES modules it was the standard way to create private scope and avoid polluting globals. Today it still appears in one-off async wrappers like (async () => { ... })() and in configuration blocks.
