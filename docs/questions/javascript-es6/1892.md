## Overview

Retry wrappers attempt operations N times multiplying delay (base ** attempt) with jitter preventing thundering herds, aborting on non-retryable errors. Combine with timeout-per-attempt and overall deadline via Promise.race/AbortController. Idempotency matters — never blind-retry POSTs that create resources.
