# Hiring manager edition: how would you describe IndexedDB to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4067**

## Overview

IndexedDB is a transactional, asynchronous, indexed object store supporting hundreds of megabytes, ideal for offline-first apps and large datasets beyond localStorage limits. Raw API is verbose; idb wrapper helps. Structured-clone storage means real Dates/Maps persist intact, unlike stringified localStorage values.
