# Senior-level follow-up: What does class fields and private fields look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2568**

## Overview

Public class fields initialize on each instance before the constructor body runs; private fields prefixed with # are enforced by the engine, truly inaccessible outside the class even via reflection. Static blocks allow complex one-time class-level initialization. Private fields throw TypeError on access rather than returning undefined, catching typos early.
