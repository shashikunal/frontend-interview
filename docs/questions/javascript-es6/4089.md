# Hiring manager edition: what common mistakes do developers make with codePointAt and unicode awareness?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #4089**

## Overview

JS strings are UTF-16 units, so astral symbols (emoji) span two code units, breaking length, indexing, and naive iteration. codePointAt/fromCodePoint handle full code points; spreading or [...str] iterates code points correctly; u-flag regexes match astral characters. Intl.Segmenter goes further for grapheme clusters like flag emoji.
