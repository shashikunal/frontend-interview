## Overview

instanceof checks whether constructor.prototype appears anywhere in the object’s prototype chain, so it fails across realms (iframe) and breaks after subclassing tricks. Classes can customize it via static Symbol.hasInstance. For cross-realm arrays rely on Array.isArray, which is realm-independent.
