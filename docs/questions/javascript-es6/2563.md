# Senior-level follow-up: What does implicit vs explicit binding look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2563**

## Overview

Implicit binding sets this to the object left of the dot at call time (obj.fn()). Explicit binding overrides it using call, apply, or bind. A subtle gotcha: passing obj.fn as a bare callback loses the implicit receiver and falls back to default binding unless you bind it first.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
