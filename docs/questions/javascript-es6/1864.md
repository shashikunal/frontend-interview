# Quick check: what does named function expressions look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #1864**

## Overview

Naming a function expression gives the internal name for recursion and stack traces without polluting outer scope: const f = function fact(n){ ... }. The binding is read-only inside. Anonymous expressions produce anonymous stack frames complicating debugging, so prefer names except trivial inline callbacks.
