# Quick check: explain Intl APIs in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4334**

## Overview

Intl.NumberFormat, DateTimeFormat, Collator and ListFormat localize numbers, dates, sorting, and lists without libraries, using BCP-47 locales. Cache formatter instances — construction is expensive. Collator fixes locale-aware alphabetical sorting that default string comparison mangles for accented characters.
