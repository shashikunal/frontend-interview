# Deep dive: What does rate limiting client requests look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2202**

## Overview

Client-side limiters queue excess requests releasing them on timers/token refills (token bucket), preventing 429 storms against constrained APIs. Implementations track in-flight counts plus waiters array; p-limit library popularizes the pattern. Combine with retry-after respect for robust integrations.
