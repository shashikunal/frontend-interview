# Quick check: what is rest parameters?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1726**

## Overview

Rest syntax (...) collects remaining arguments into a real array in function signatures, or remaining keys in destructuring. Unlike the legacy arguments object, rest is a true array with array methods, works in arrow functions, and must be the last parameter. Rest and spread share syntax but serve opposite directions.
