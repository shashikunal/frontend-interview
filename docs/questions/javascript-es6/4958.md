# Interview scenario — what common mistakes do developers make with replaceAll?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4958**

## Overview

replaceAll(search, replacement) swaps every occurrence without the g-flag ceremony, accepting strings (literal, not regex semantics) or global regexes — non-global regex throws deliberately to prevent accidental single-replace bugs. Replacement patterns like $& still apply. Cleaner than split/join hacks.
