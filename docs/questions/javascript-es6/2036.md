# Deep dive: How would you describe WeakMap and WeakSet to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2036**

## Overview

WeakMap/WeakSet hold objects weakly: entries are removed automatically when the key becomes unreachable elsewhere, preventing memory leaks in caches and metadata registries. Keys must be objects, contents are not iterable, and size is unobservable — deliberate design for lifetime-safe association.

- Array iteration methods

- Immutability considerations

## Syntax & Examples

### map() - Transform

```javascript
const numbers = [1, 2, 3]
const doubled = numbers.map(n => n * 2)
// [2, 4, 6] - new array, same length
```

map() creates a new array with transformed values. Returns a new array.

### forEach() - Side Effects

```javascript
const numbers = [1, 2, 3]
numbers.forEach(n => console.log(n * 2))
// Logs: 2, 4, 6
// Returns: undefined
```

forEach() executes a function for each element. Returns undefined, used for side effects only.

### reduce() - Accumulate

```javascript
const numbers = [1, 2, 3]
const sum = numbers.reduce((acc, n) => acc + n, 0)
// 6 - single accumulated value
```

reduce() reduces array to a single value. Powerful for transformations, grouping, and computations.
