> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #378**

## Overview

String.replace accepts a function receiving (match, groups..., offset, string) whose return substitutes dynamically — essential for templating, escaping, and case transformations. Without the g flag only the first occurrence changes, a frequent bug. replaceAll exists precisely to make global replacement explicit.
