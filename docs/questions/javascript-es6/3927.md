# Onsite panel edition: What is transpilation vs polyfilling distinction?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #3927**

## Overview

Transpilers rewrite new syntax to old equivalents (arrow→function); polyfills supply missing runtime APIs (Promise). Babel handles syntax via plugins, runtime methods via core-js preset-env integration. Missing either piece breaks differently — syntax errors parse-fail loudly, absent APIs fail mysteriously at runtime.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
