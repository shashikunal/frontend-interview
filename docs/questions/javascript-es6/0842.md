# Explain pass by sharing semantics in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #842**

## Overview

JS passes references-to-values: reassigning parameters inside functions never affects caller variables, but mutating shared objects/arrays does. This hybrid explains why defensive cloning at boundaries matters for primitives-like safety with objects, and why const does not prevent content mutation.
