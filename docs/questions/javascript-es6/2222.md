# Deep dive: What does polyfill strategy and core-js costs look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2222**

## Overview

Polyfills patch missing natives conditionally (if (!Array.at) ...). Bundlers inject targeted polyfills from browserslist targets — aggressive legacy support inflates bundles dramatically (core-js). Audit usage: drop IE-era targets, prefer transpile-only where possible, load polyfills asynchronously non-blocking when optional.
