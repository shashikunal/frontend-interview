# Whiteboard prompt: Explain top-level await in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3247**

## Overview

Modules may await directly at top level, simplifying config loading and WASM instantiation bootstraps. The module’s evaluation blocks importers — powerful yet risky for circular deps or startup latency, so prefer lazy dynamic imports when delay matters. Only ESM supports it; CommonJS does not.

## Key Concepts

- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
