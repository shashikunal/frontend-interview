# What common mistakes do developers make with cancellation patterns pre-AbortController?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1085**

## Overview

Historical cancellation used token flags checked between steps, wrapped promises racing a cancel promise, or generator-based cooperative schedulers (bluebird cancellation). AbortController standardized signal threading for fetch/listeners; custom long computations still need manual checkpoint polling of signal.aborted.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
