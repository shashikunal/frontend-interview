## Overview

Reflect mirrors Object/operation APIs as functions returning explicit results instead of throwing, pairing with Proxy traps for correct default forwarding: Reflect.get(target, key, receiver). It makes metaprogramming uniform and avoids awkward try/catch around defineProperty-style operations when testing capabilities.
