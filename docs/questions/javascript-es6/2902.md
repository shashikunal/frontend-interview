# Rapid fire: what common mistakes do developers make with CommonJS vs ESM?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2902**

## Overview

CommonJS loads synchronously via require with value copies of exports, dominating legacy Node code; ESM is async, static, tree-shakeable, and standard across browsers and modern Node. Interop quirks: default export wrapping, __dirname absence in ESM (derive from import.meta.url). New libraries should ship ESM first.
