## Overview

Async iterables implement Symbol.asyncIterator; for await...of consumes streams page-by-page, pausing between chunks without callback pyramids. Async generators (async function*) produce them naturally, ideal for paginated APIs and event streams. Errors propagate like sync loops; breaking calls iterator.return cleanup.
