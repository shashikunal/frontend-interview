# Rapid fire: explain sequential vs parallel async decisions in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #3049**

## Overview

Parallelize independent operations via Promise.all for latency wins; sequence dependent calls where output feeds input or APIs demand ordering/rate limits. Batch strategies chunk large arrays (map to promises, all per chunk) bounding memory and server pressure while preserving throughput.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
