# How would you describe ES modules to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #323**

## Overview

ESM uses import/export with statically analyzable syntax, enabling tree shaking, circular-reference handling via live bindings, and deferred async loading. Modules are strict-mode by default and singleton per specifier. Dynamic import() returns a promise for lazy chunks, and import.meta exposes module metadata like url.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
