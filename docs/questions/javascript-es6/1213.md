# How would you describe live bindings meaning to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #1213**

## Overview

Exported let counters update in importers because ESM exports bind names, not snapshot values — reading importedVar reflects latest assignment. CommonJS copies primitive exports at require time instead. Live bindings enable observable module state but surprise developers expecting frozen constants; prefer const exports for clarity.
