# Phone screen edition: explain async function return value rules in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3550**

## Overview

An async function always returns a promise; returned values get wrapped, thrown errors reject, and returning a promise awaits it transparently. Therefore calling .then twice on the same async result sees identical data, and forgetting await inside another async call silently produces unresolved promise bugs — enable no-floating-promises linting.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
