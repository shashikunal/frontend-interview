# Explain callback hell and its remedies in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1057**

## Overview

Nested callback pyramids grow when each step needs the previous result: login(user, u => getPosts(u, p => ...)). Remedies: named function hoisting flattening indentation, promise chains linearizing steps, and async/await reading sequentially. Error handling consolidates into single catch versus per-level error callbacks.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
