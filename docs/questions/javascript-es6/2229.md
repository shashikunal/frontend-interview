# Deep dive: What is default vs named export guidance?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2229**

## Overview

Named exports tree-shake, rename safely, and autocomplete reliably; default exports allow arbitrary importer naming hurting grep-ability and causing inconsistent casing drift. Communities diverge (React default, lodash named). Pick team-consistent policy; components commonly default while utilities lean named.
