# Quick check: what does bind chaining limitations look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1874**

## Overview

Bound functions lock this permanently — rebinding a bound function has no effect since bind output ignores subsequent call/apply this arguments. They also lack prototype (cannot new), carry length trimmed by bound args, and memoize bound results to avoid unbounded wrapper allocation in hot paths.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
- Prototype chain
- Object.create()
- Constructor functions
