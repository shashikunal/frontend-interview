# Explain shallow vs deep copy in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #112**

## Overview

Shallow copies (spread, Object.assign, Array slice) duplicate only the top level; nested references are shared, so mutating them leaks into the original. Deep copies duplicate recursively — structuredClone handles Dates, Maps, Sets, and cycles natively, while JSON round-tripping drops functions, undefined, and Symbols and mangles Dates into strings.
