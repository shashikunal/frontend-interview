# Phone screen edition: what is default parameters?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #3434**

## Overview

Default parameter values kick in when an argument is undefined (not null or 0), and may reference earlier parameters, enabling derived defaults. Each call evaluates the expression freshly. Defaults replace many manual x = x || fallback lines while avoiding falsy-value bugs that || introduces.
