# Explain graceful degradation definition in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1347**

## Overview

Graceful degradation builds for modern capability first then provides fallbacks downward; progressive enhancement ascends oppositely from baseline. Practical middle ground: feature-detect enhancements, provide usable fallback content (image in canvas absence), communicate constraints honestly rather than blank screens.
