# Deep dive: What common mistakes do developers make with event emitter pub-sub implementation?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #2178**

## Overview

Minimal emitter stores Map<event, Set<handler>>; on adds, emit iterates copying set (handlers may unsubscribe mid-flight), off removes, once wraps auto-unsubscribing. Support wildcard or async handlers deliberately. Memory leaks lurk when emitters outlive subscribers — provide dispose hooks and weak patterns where sensible.
