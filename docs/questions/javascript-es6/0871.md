# What is new.target?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #871**

## Overview

Inside constructors new.target is the invoked constructor (undefined if called plainly), enabling dual-purpose functions that self-heal missing new: if (!new.target) return new Foo(...). ES2015+ classes throw without new automatically, so this guard mainly serves legacy-style constructor functions and subclass detection.
