# Onsite panel edition: What does Object.seal look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3710**

## Overview

Object.seal prevents adding or removing properties but leaves existing values writable. Freeze goes further by locking values too. Both are shallow operations. Sealing suits records with a fixed shape whose contents change; freezing suits constants and shared configuration.
