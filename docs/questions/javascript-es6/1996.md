# Deep dive: How would you describe the new operator to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1996**

## Overview

new creates a fresh object whose prototype is set to ConstructorFn.prototype, invokes the constructor with this bound to the new object, and either returns that object or an explicit object returned by the constructor. Returning a primitive is ignored; returning a new object replaces the result. This explains factory-versus-constructor behavior differences.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
- Prototype chain
- Object.create()
- Constructor functions
