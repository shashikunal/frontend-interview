# What is the arguments object?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #811**

## Overview

Non-arrow functions receive array-like arguments with length and indexed access but no array methods; converting via [...arguments] or Array.from fixes that. Arrow functions see enclosing arguments lexically. Rest parameters supersede it in modern signatures, providing true arrays with named intent.
