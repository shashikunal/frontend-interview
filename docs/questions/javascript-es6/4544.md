# Deep dive: What does block scope vs function scope look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4544**

## Overview

Function scope means variables declared in a function are visible anywhere inside it (var). Block scope confines let/const to the nearest curly-brace pair — an if, for, or bare block. Block scope prevents accidental leakage, enables safe loop variables per iteration with let, and makes refactoring safer.
