# What common mistakes do developers make with execution context and the call stack?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #775**

## Overview

Each function invocation creates an execution context holding locals, scope chain, and this, pushed onto the call stack and popped on return. Stack overflow occurs when recursion exceeds capacity. Synchronous single-stack execution is why blocking loops freeze everything — async APIs exist to defer work off this stack.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
