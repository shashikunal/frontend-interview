# Whiteboard prompt: Explain Blob and FileReader in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #3227**

## Overview

Blobs represent immutable binary data; URLs via URL.createObjectURL enable downloads and media previews (revoke to free memory). FileReader asynchronously reads blobs as text/dataURL/arrayBuffer, though blob.arrayBuffer()/text() promise methods now cover most needs. Canvas.toBlob exports drawings for upload pipelines.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
