# How would you describe URL and URLSearchParams to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #523**

## Overview

URL parses/builds absolute and relative hrefs exposing protocol, pathname, searchParams with typed get/set/append/delete/has and iteration. URLSearchParams encodes properly, avoiding manual encodeURIComponent mistakes. Combining them beats regex surgery on query strings and handles edge cases like encoded slashes gracefully.
