# Quick check: what is preventDefault vs stopPropagation?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4348**

## Overview

preventDefault cancels the browser default action (link navigation, checkbox toggle, form submit) while propagation continues; stopPropagation stops ancestor listeners without touching defaults. They answer different questions — "should the browser act?" versus "should ancestors hear?" — and frequently both are needed together.
