# What does once() utility implementation look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #949**

## Overview

once wraps a function so subsequent calls replay the first result: closure boolean flag plus cached value. Edge cases include preserving this and arguments of first call only. Useful for initialization guards (singleton connections, lazy singletons) replacing scattered initialized booleans throughout codebases.
