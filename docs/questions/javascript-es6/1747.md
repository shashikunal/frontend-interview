# Quick check: explain recursion in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #1747**

## Overview

Recursion solves problems by having a function call itself on smaller inputs toward a base case. JavaScript engines mostly lack tail-call optimization in practice, so deep recursion risks stack overflow; convert hot paths to iteration or trampolines. Trees, JSON traversal, and parsers are naturally recursive domains.
