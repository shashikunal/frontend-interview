# Interview scenario — explain IntersectionObserver in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4925**

## Overview

IntersectionObserver asynchronously reports element visibility intersections with viewport thresholds without scroll-janky geometry polling. Powers lazy-loading images, infinite scroll triggers, view-impression analytics, and header shrink effects. Callbacks deliver entries with isIntersecting and intersectionRatio; disconnect() cleans up subscriptions.
