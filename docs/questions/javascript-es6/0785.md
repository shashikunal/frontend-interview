# What common mistakes do developers make with scope chain lookup?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #785**

## Overview

Identifier resolution walks outward through nested lexical environments until found, throwing ReferenceError at global miss. Shadowing occurs when inner declarations reuse outer names, hiding them. Deep chains cost lookup time marginally, but clarity argues for shallow nesting and explicit parameter passing over long-distance variable capture.
