# Quick check: explain prototypal inheritance in depth.

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #4269**

## Overview

Objects inherit directly from other objects via the [[Prototype]] link, accessible through __proto__ or Object.create. Property lookups walk up this chain until found or null. Unlike class-based inheritance, delegation is live: changing a prototype affects existing instances immediately.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
- Prototype chain
- Object.create()
- Constructor functions
