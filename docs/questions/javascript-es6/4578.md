# Deep dive: How would you describe setTimeout and setInterval to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4578**

## Overview

setTimeout schedules a macrotask after at least the given delay; nesting deeper than five levels clamps delays to 4ms. setInterval re-queues every interval but overlapping executions pile up if handlers exceed the interval — recursive setTimeout is safer. Delays are minimums, not guarantees, since busy main threads postpone execution.
