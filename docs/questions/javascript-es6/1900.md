# Quick check: what common mistakes do developers make with throttling scroll with passive listeners?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #1900**

## Overview

Passive listeners ({passive:true}) promise no preventDefault, unlocking immediate scrolling instead of waiting handler completion — default for touch/wheel in Chrome. Combine passive wheel/touch listeners with rAF-batched position reads to eliminate jank; never passive where you cancel defaults.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
