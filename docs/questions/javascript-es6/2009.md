# Deep dive: What is spread syntax?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2009**

## Overview

Spread (...) expands iterables into argument lists or array literals and enumerates own enumerable props into object literals. It builds concise clones and merges ({ ...a, ...b } later keys win) and converts iterables like NodeList or Set to arrays. Spread is always a shallow operation — nested objects stay shared.
