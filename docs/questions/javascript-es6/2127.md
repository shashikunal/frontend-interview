# Deep dive: What does SharedArrayBuffer and Atomics look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2127**

## Overview

SharedArrayBuffer shares raw bytes across threads; Atomics supplies synchronized read-modify-write ops (add, compareExchange, wait/notify) preventing torn reads and enabling worker coordination. Browsers require cross-origin isolation headers (COOP/COEP) due to Spectre mitigations. Use for parallel number crunching, not general app state.
