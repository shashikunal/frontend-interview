# What does object key ordering rules look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #919**

## Overview

Integer-like keys enumerate ascending numerically first; string keys follow insertion order; Symbols last in insertion order. This hybrid ordering surprises developers expecting pure insertion sequence ({"2":x,"1":y}). Numeric ids stored as strings reorder unexpectedly — pad or prefix when order fidelity matters.

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this
