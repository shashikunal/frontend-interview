# Interview scenario — what does nested destructuring patterns look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #4937**

## Overview

Destructuring supports arbitrarily nested paths mixing arrays and objects: const { meta: { tags: [first] } = [] } = payload. Defaults apply per-level, so guarding intermediate undefined nodes needs defaults at each nesting step. Overly clever one-line extraction hurts readability more than it saves typing.
