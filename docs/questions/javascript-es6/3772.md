# Onsite panel edition: What is splice vs slice?

> **Category:** JavaScript & ES6 | **Difficulty:** Hard | **Question #3772**

## Overview

splice mutates, removing/inserting items at an index and returning removed elements; slice copies a section non-destructively. Confusing them causes ghost bugs. Modern immutable updates favor slice/spread/toSpliced, reserving splice for deliberate in-place edits on large arrays where copying costs matter.
