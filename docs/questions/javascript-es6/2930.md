# Rapid fire: how would you describe localStorage vs sessionStorage vs cookies to a teammate?

> **Category:** JavaScript & ES6 | **Difficulty:** Easy | **Question #2930**

## Overview

localStorage persists ~5MB per origin indefinitely; sessionStorage dies with the tab; cookies (~4KB) ride every HTTP request enabling server reads with Secure/HttpOnly/SameSite attributes. Store non-sensitive UI state locally, auth in HttpOnly cookies, and never secrets in localStorage where XSS can read them.
