# Interview scenario — what does await inside loops pitfalls look like in practice, and when does it matter?

> **Category:** JavaScript & ES6 | **Difficulty:** Medium | **Question #2415**

## Overview

Sequential awaits in forEach callbacks break entirely (forEach ignores promises), and for-loop awaits serialize independent requests multiplying latency. Parallelize with Promise.all(map(fetch)), or use for-await-of when order/dependency demands sequence. Measure batches: N sequential 100ms calls cost N*100ms versus ~100ms parallel.

## Key Concepts

- Promise states: pending, fulfilled, rejected
- Promise chaining with .then() and .catch()
- Promise.all(), Promise.race(), Promise.allSettled()
- Async function returns Promise
- Await pauses execution
- Error handling with try/catch
