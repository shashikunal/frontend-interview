# Output tracing 3: what will this code log, and why?

> **Category:** DOM Advanced APIs | **Difficulty:** Hard | **Question #10032**

## Overview

Expected output: "a=1&m=13&z=26"

sort() reorders entries alphabetically by name, producing a canonical query string independent of original order, useful for cache keys and signatures.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this

## Syntax & Examples

### this Binding Rules

```javascript
// Default binding
function foo() { console.log(this) }
foo() // window (or undefined in strict)

// Implicit binding
const obj = { foo: function() { console.log(this) } }
obj.foo() // obj

// Explicit binding
foo.call(obj) // obj

// new binding
new foo() // new instance

// Arrow function (lexical)
const arrow = () => console.log(this)
arrow() // enclosing scope's this
```

this is determined by how a function is called (call-site), not where it's defined. Arrow functions inherit this lexically.
