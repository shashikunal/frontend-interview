# Output tracing 9: what will this code log, and why?

> **Category:** DOM Advanced APIs | **Difficulty:** Medium | **Question #10044**

## Overview

Expected output: false false undefined

Without an init dict, bubbles and cancelable default to false and detail is undefined, which is why listeners on ancestors never fire and payload reads yield undefined.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this

## Syntax & Examples

### this Binding Rules

```javascript
// Default binding
function foo() { console.log(this) }
foo() // window (or undefined in strict)

// Implicit binding
const obj = { foo: function() { console.log(this) } }
obj.foo() // obj

// Explicit binding
foo.call(obj) // obj

// new binding
new foo() // new instance

// Arrow function (lexical)
const arrow = () => console.log(this)
arrow() // enclosing scope's this
```

this is determined by how a function is called (call-site), not where it's defined. Arrow functions inherit this lexically.
