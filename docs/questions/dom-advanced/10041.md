# Code output challenge 8: predict what this snippet logs.

> **Category:** DOM Advanced APIs | **Difficulty:** Medium | **Question #10041**

## Overview

Expected output: false true 7

A cancelable event vetoed via preventDefault makes dispatchEvent return false and sets defaultPrevented; detail passes payload untouched, here the id 7.

## Key Concepts

- Call-site binding
- Implicit, explicit, new, and default binding
- Arrow function lexical this

## Syntax & Examples

### this Binding Rules

```javascript
// Default binding
function foo() { console.log(this) }
foo() // window (or undefined in strict)

// Implicit binding
const obj = { foo: function() { console.log(this) } }
obj.foo() // obj

// Explicit binding
foo.call(obj) // obj

// new binding
new foo() // new instance

// Arrow function (lexical)
const arrow = () => console.log(this)
arrow() // enclosing scope's this
```

this is determined by how a function is called (call-site), not where it's defined. Arrow functions inherit this lexically.
